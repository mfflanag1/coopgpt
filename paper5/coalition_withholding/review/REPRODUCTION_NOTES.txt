FOCUSED PORTABLE REPLAY — ACTUAL RESULTS AND COMMANDS
18 October 2026

From the root of this paper package, run:

    python3 reproduce.py

This creates a new temporary output directory and prints its location. To
choose a destination, give a directory that does not already exist:

    python3 reproduce.py --out ./verification/replay/my-new-run

Requirements: Python 3 and its standard library only. All six selected jobs
run by default. No SciPy/NumPy option, installs, network access, or external
source-tree access is required. Do not use -O/-OO; unset PYTHONOPTIMIZE for
ordinary launches. The runner refuses an optimized interpreter before
creating output, and removes inherited PYTHONOPTIMIZE from checker processes.

Package layout
  reproduce.py
    A focused adaptation of the hardened campaign reproduce_campaign.py.
    Retains isolated job directories, unchanged input copies and hash checks,
    per-job stdout/stderr, explicit parsed PASS verdicts, and failure exits.
    Adds a recorded child-process assertion-mode check, input-manifest
    verification, and a final check that packaged scientific inputs are
    unchanged. The original basic/extended split was removed because every
    selected checker is standard-library compatible.
  evidence/checks/MANIFEST.json
    Original campaign-relative paths, byte sizes, and SHA-256 hashes for all
    nine preserved scientific checker/fixture files. It also records the hash
    of the source campaign runner, which was adapted rather than copied as a
    scientific checker. The historical absolute source path is provenance
    metadata only; the portable runner reads its package-relative files.
  verification/replay/FRESH_COPY_MANIFEST.json
    Hashes for the fresh package copy used in the actual run.
  verification/replay/fresh_package/
    A separate copy of reproduce.py and the complete selected evidence tree.
  verification/replay/fresh_results/REPLAY_REPORT.json
    Actual successful report, with input hashes, commands, durations, parsed
    verdicts, generated-file hashes, and paths to every stdout/stderr log.
  verification/replay/guard_checks/GUARD_RESULTS.json
    Negative checks for -O, -OO, and an already-existing output directory.
  verification/replay/VALIDATION.json
    Final copy, assertion-mode, verdict, and campaign-source byte checks.

Actual fresh-copy execution
  Working directory: verification/replay/fresh_package
  Command:

    env PYTHONOPTIMIZE=1 python3 -E reproduce.py --out ../fresh_results

  This intentionally starts an unoptimized parent using -E while leaving
  PYTHONOPTIMIZE in the inherited environment. The child-mode probe recorded
  optimize=0 and assertions_enabled=true, and the report records that the
  inherited flag was removed. Thus the run tests the exact inherited-flag
  failure mode the hardened runner is intended to prevent.

  Runtime used here: /opt/homebrew/opt/python@3.15/bin/python3.15.
  All six jobs returned exit code 0 and an explicit PASS verdict.
  Aggregate checker time was approximately 28.0 seconds on this machine.
  This is a measured local duration, not a runtime guarantee.
