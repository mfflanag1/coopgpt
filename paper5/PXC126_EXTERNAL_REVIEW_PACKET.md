## Claimed theorem

Fix the actual Lmax top block `H`, let `R=N\H`, and put

```text
a_i=min(x_i,z_i),  b_i=max(x_i,z_i).
```

For two proper coalition rows `C,Q`, their membership bits partition `R`
into four cells `V11,V01,V10,V00`. Choose distinct representatives
`u11,u01,u10,u00` and set

```text
P_square=(a_u11-b_u01)_+ + (a_u10-b_u00)_+.
```

PXC126a–b claims only

```text
P_square <= O-B_H.
```

At any threshold, each active summand uses a high-in-both player and a
low-in-both player. The two pairs have disjoint endpoints, so their active
count is bounded by the minimum of the high–high and low–low counts. The
layer-cake identity `(LC)` integrates that minimum to `O-B_H`.

For fixed `C,Q`, PXC126c records the separated optimum

```text
(max_V11 a-min_V01 b)_+ + (max_V10 a-min_V00 b)_+.
```

This is immediate because the four cells are disjoint; an empty cell means
that pair of rows supplies no square.

In the only positive-demand PXC125 case, `t=1`, use `C=rhbK`, `Q=rhaK` and
representatives `(K,a,b,j)`. The two lengths become exactly

```text
B-A,  (min(B,C)-2A)_+.
```

For `t>=2` the same square is a smaller valid subpacking than PXC125's
two-distinct-`K` price; that branch already has `D_H=0`. This is not a
restriction, contraction, amalgamation, oriented-matroid minor, or complete
canonical-rectangle packing.

## Refuted statement, never claimed as a theorem

`PXC126?` asked whether every positive-demand PXC114 common obstruction has
such a square, generated by a retained common row and a basic staged
outside-union blocker, with `P_square>=D_H`. Its exact negation is a
positive-demand common obstruction for which every eligible square is below
`D_H`. PXC127 supplies such an exact game: every eligible square has an empty
cell and price zero while `D_H=2/3`. The same witness has a stronger common-row
cut price `37/5`, so it refutes square extraction but not hybrid overlap.
