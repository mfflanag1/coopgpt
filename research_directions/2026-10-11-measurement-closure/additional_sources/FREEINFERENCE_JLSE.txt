ADDITIONAL SOURCES: FREEINFERENCE AND ARGONNE JLSE
Checked 11 October 2026. Bounded public documentation audit; no physical run,
account creation, restricted access, data request or external message.

FreeInference / Harvard MadSys
https://data.agentic-system.org/
https://github.com/HarvardMadSys/freeinference_agentic_trace
https://huggingface.co/datasets/harvardMadsys/freeinference_agentic_trace

The hub advertises released request/session metadata and separate GPU/serving
telemetry. Request fields include gateway start/end, TTFT, model, anonymized
provider and token counts; prompt text is withheld. The fleet telemetry describes
GPU/node identifiers, watts and engine averages at one-minute sampling, with
coarser rollups. No documented request-to-GPU join was established. The public
session release ends 5 September 2026; advertised rolling telemetry history on
11 October does not establish historical overlap. These are useful workload and
fleet-description sources, but they cannot be treated as matched two-hardware
request-energy observations. No released counterfactual paired workload is shown.

The standard HTTP client received 403 for both the small snapshot API and linked
markdown field reference. The web tool identified the snapshot as JSON without
exposing its content; the field reference was rejected for unsupported markdown
content type. No telemetry payload was acquired or used for estimation. The
conclusion above is documentation-based, not a validation of raw fleet records.
No bulk request traces were downloaded. The trace repository declares CC BY 4.0.

Argonne Joint Laboratory for System Evaluation
https://www.jlse.anl.gov/projects/benchmarking/data-center-flexibility-dataset

The official project page describes a planned B200/H100 study combining control
changes, GPU/CPU/DRAM power and per-request quality-of-service measurements, with
electricity-market and demand-response applications. This is unusually relevant
to the user's energy direction. The inspected page supplies a project description,
not a downloadable measurement release. Prospective work must not be described as
data already obtained. No access application or contact was made.

Disposition: neither inspected source closes the current paired-measurement gate.
Useful future data targets; no adapter or additional simulator justified by this
evidence alone. Suitable new raw releases or existing GPU access are still needed.
