FIXED POSITIVE COMPOSITION OF THE CAMPAIGN RESULTS
16 October2026. Routine transfer lemma; not an additional novelty claim.

Let actual owner set N be fixed. Suppose an original capacity vector c is sent
by fixed nonnegative linear maps L_j into component reports, and every actual
coalition S satisfies the exact public technology identity
 V(S;c)=sum_j w_j F_j(S;L_j c), with fixed w_j>=0.
All component mechanisms use the same actual owners, including zero owners.
The maps and weights do not depend on strategic reports. A finite sum suffices;
a measurable positive integral works when all quantities are finite.

If each component payment Y^j is nonnegative, own-report monotone, coalition-
covering, and funded by gamma F_j, then Y_i=sum_j w_jY_i^j has the same three
properties and total<=gamma V(N). Coordinatewise report increases raise every
component report of the SAME actual owner; sum the component monotonicity
inequalities. Coalition coverage and funding follow from the exact identity.
No virtual owner incentive or report-dependent reallocation of identities is used.

If components instead have raw rules N^j and own-report envelopes E^j, the
envelope of the sum satisfies
 sup_{c_i'<=c_i} sum_j w_j N_i^j(L_j(c_i',c_-i))
 <=sum_j w_j sup_{u_i<=L_jc_i}N_i^j(u_i,L_jc_-i)
 =sum_j w_jE_i^j.
The same actual underreport may correlate component changes; this only reduces
the left supremum. Thus a common component envelope bound gives the same bound
for the sum's own-report envelope, as well as for the summed-envelope rule.

SHARP NONLINEAR RESPONSE TRANSFER (CONDITIONAL ON COMPONENT THEOREM)
Suppose each component raw local rule is own-monotone and satisfies
 L_i^j<=K sqrt(z_i^j D_i^j), with D_i^j>=0 the actual own-payment loss.
For aggregate z_i=sum_j w_jz_i^j and D_i=sum_j w_jD_i^j,
 sum_{k!=i}(z_k-z_k')_+
 <=sum_j w_jL_i^j
 <=K sum_j sqrt[(w_jz_i^j)(w_jD_i^j)]
 <=K sqrt(z_iD_i).
Thus the same response constant survives fixed positive public layers,
including correlated original-coordinate underreports. This is ordinary
positive-part subadditivity and Cauchy--Schwarz, not a new resource model.

checking them on each layer: P+M<=H at one aggregate level need not imply it
at every public-value threshold. The separated-grid theorem avoids that issue
because it is all-profile on its stated ownership class.

Economic interpretation remains a static divisible-production model with binding
capacity underreports and payment utility. Public productivity/energy prices
are fixed coefficients, not private costs. This transfer establishes neither
measured serving throughput nor latency, grid-flow feasibility, opportunity-cost
