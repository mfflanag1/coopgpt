CANDIDATE THEOREM: A UNIFORM1.968 BOUND FOR THE ACTUAL NESTED ENVELOPE
16 October2026. Conventional proof candidate awaiting independent audit. Priority unassessed.

THEOREM (MODEL B). Arbitrarily many fixed actual owners hold arbitrary nonnegative bundles (h_ij,l_ij,p_i) on the depth-two technology. Reports are binding coordinatewise underreports; utility is payment only. Let z_i be the sum of the known mixed-owner two-pool exponential payments on each local branch (h_j,l_j), and let N_i be the same two-pool rule applied to (H_i,p_i+z_i), H_i=sum_j h_ij. Define
 E_i(b)=sup_{0<=b'_i<=b_i} N_i(b'_i,b_-i).
Then E is nonnegative, whole-bundle own-report monotone, covers every coalition at every report, and
 sum_i E_i(b) <= (246/125) F(b),
where F=min(H,P+M), H=sum_i H_i, P=sum_i p_i, M=sum_j min(h_j,l_j). Both owner and branch counts are unrestricted. The constant is deliberately coarse.

KNOWN PRIMITIVE USED. For accounts a_i,b_i, A=sum a,B=sum b,T=min(A,B), if A<=B and T>0 set rho=sum_i min(b_i,T)/T, q=(1/2)exp(1-rho), and pay (1-q)a_i+q min(b_i,T). Swap a,b if B<A. At T=0 pay0. The merged mixed-owner rule is continuous, own-coordinate nondecreasing, coalition-covering for min(a(S),b(S)), and has total at most C T, C=1+1/(2e)<6/5. At ties the payment is(a_i+b_i)/2. We use these previously proved properties, not a new cloning argument.

1. LOCAL ROLE BOUND.
Write z_i=z_i^h+z_i^l, keeping the hardware and local-power components of each local rule separately. Then z_i^h<=H_i and
 sum_i z_i^l <= H/2.                                                     (1)
Proof branchwise. If h<=l, local power is long, so its total payment is (h/2)rho exp(1-rho)<=h/2 because rho>=1. If h>=l>0, local power is short and receives (1-q)l. Write eta=h/l>=1 and rho=sum_i min(h_i,l)/l<=eta. Hence q>=(1/2)exp(1-eta) and
 (1-q)l <= [1-(1/2)exp(1-eta)]l <= h/2,
using eta+exp(1-eta)>=2, whose derivative is1-exp(1-eta)>=0. Zero pools are immediate. Summing proves(1). Also Z=sum z_i<=C M.

2. WHY THE RANGE RELAXATION IS LEGITIMATE.
Fix full profile b and owner i. For an arbitrary underreport b'_i, first restore ONLY its shared-power report p_i. N_i can only increase, because local z is independent of shared power and the outer primitive is own-account monotone. Thus, in bounding its supremum, all owners' shared-power reports equal their full values.
Let z'_k be the local payments at the remaining local underreport. Own monotonicity gives z'_i<=z_i, while local budget and production monotonicity give sum_k z'_k<=C M'<=C M. In the outer primitive ONLY, restore owner i's hardware account from H'_i to H_i, holding all p_k+z'_k fixed. The outer primitive again can only increase i's payment. This is an inequality in its independent account space, not an assertion about a feasible physical report or a change of actual ownership.
After these two valid monotonicity steps, the entire outer hardware vector equals the fixed full vector a_i=H_i. The owner-specific opposing vector b'_k=p_k+z'_k satisfies SIMULTANEOUSLY
 b'_i <= B_i:=p_i+z_i,
 P <= sum_k b'_k <= K:=P+C M,
 b'_k>=p_k for every k.                                                 (2)
Every owner may face a different vector b'; our bounds below are individual inequalities uniform over all vectors obeying(2), then summed using the same full-profile A_i,B_i.
Let D_+=sum_i(B_i-H_i)_+, D_-=sum_i(H_i-B_i)_+. From(1),
 D_+ <= P+sum_i(z_i-H_i)_+ <= P+H/2,                                    (3)
and sum B_i=P+Z<=K. Notice that(2) retains the actual full own-payment ceiling; no sum of external-influence magnitudes is used.

3. TRUTHFULNESS AND COVERAGE.
The supremum domain for E_i expands under an increase of its own report, proving whole-bundle monotonicity. It includes the full report, so E_i>=N_i. For any real coalition S, z(S)>=M(S), and outer coverage gives N(S)>=min(H(S),p(S)+z(S))>=F(S). Finiteness follows from the bounds below (also from continuity on the compact own-report box). Zero grand value implies zero local and outer values at every underreport, so E=0.

4. THE CASE K<=H.
All restored outer profiles have B'=sum b'_k<=K<=H, so opposing accounts form the short pool. For T=B'>0 write d_i(T)=min(H_i,T), rho(T)=sum d_i(T)/T and q(T)=(1/2)exp(1-rho(T)). As T increases, rho is nonincreasing and q is nondecreasing. The individual payment is b'_i+q(T)(d_i(T)-b'_i). If the parenthesis is negative, it is at most B_i. Otherwise it is at most B_i+q(K)d_i(K). Consequently
 sum E_i <=sum B_i+q(K)sum d_i(K)<=K+K/2=(3/2)K.
Here rho(K)>=1 and rho exp(1-rho)<=1. Since P+M<=K<=H, F=P+M, while K<=C(P+M). Thus
 sum E_i <=(3C/2)F <(9/5)F.                                            (4)
If K=0 all payments vanish.

5. THE CASE P>=H>0.
Every restored outer profile has B'>=P>=H and hardware is short. Set a_i=H_i/H, u_i=min(p_i,H)/H, v_i=min(B_i,H)/H, U=sum u_i>=1. An owner's payment exceeding H_i requires d_i=min(b'_i,H)>H_i. Since other opposing accounts are at least p_k, its excess is at most
 (H/2)exp(1-U) exp(-(d_i/H-u_i))(d_i/H-a_i).
The function exp(-x)(x-a_i) is increasing on a_i<=x<=1, so replace d_i/H by v_i. Then drop exp(-(v_i-u_i))<=1. Also
 sum_i(v_i-a_i)_+ <= U+sum_i(z_i-H_i)_+/H <=U+1/2.
Therefore
 sum E_i/H <=1+(1/2)exp(1-U)(U+1/2)<=7/4,                               (5)
because the last excess is decreasing for U>=1. In this case F=H.

6. THE INTERMEDIATE CASE P<H<K.
Normalize p=P/H in[0,1), m=M/H in[0,1], k=K/H=p+C m>1, f=F/H=min(1,p+m). Put
 q0=(1/2)exp(1-k),
 q1=0 if p=0, and q1=(1/2)exp(1-1/p) otherwise.
Both lie in[0,1/2]. At EVERY restored profile satisfying(2),
 if H_i>=B_i: payment_i <=(1-q0)H_i+q0 B_i;
 if H_i<=B_i: payment_i <=q1 H_i+(1-q1)B_i.                             (6)
Proof of first line. If hardware is short, capped opposing ratio<=B'/H<=k, so q>=q0 and min(b'_i,H)<=B_i<=H_i. If hardware is long, payment is b'_i+q(min(H_i,B')-b'_i)<= (H_i+B_i)/2, which is at most the asserted expression because q0<=1/2.
Proof of second line. If hardware is short, q<=1/2 gives payment<=(H_i+B_i)/2, at most the asserted expression. If hardware is long and b'_i<=H_i, payment<=H_i. Otherwise b'_i>H_i, and payment=b'_i-q(b'_i-H_i). For p>0, rho<=H/B'<=H/P=1/p, so q>=q1; replacing b'_i by B_i increases this bound. For p=0, q1=0 and payment<=B_i directly.
Sum(6), use D_+-D_-=sum B_i-H, then(3). Since1-q0-q1>=0,
 sum E_i/H <=1+q0(k-1)+(1-q0-q1)(p+1/2)
             =3/2+p-q1(p+1/2)+q0(C m-3/2).                            (7)
We now bound this elementary expression with rational constants.

Elementary facts: C<6/5; q1>=(p-1/2)_+. For the second, if p>=1/2, exp(1-1/p)>=2-1/p gives q1>=1-1/(2p)>=p-1/2; the last difference is (p-1/2)(1-p)/p. If p<=1/2 use q1>=0.

6a. If f=1, then C m-3/2<-3/10 and k<=1+C. Thus q0>1/8: indeed exp(C)<exp(6/5)<4, since e<3 and exp(1/5)<5/4. Also
 3/2+p-(p-1/2)_+(p+1/2)<=2 for0<=p<=1.
Equation(7) gives sum E_i/H<2-3/80=157/80. Since F=H, this is the desired factor here.

6b. If f=p+m<1, then m<1-p and k<=C<6/5, so q0>(1/2)(2-k)>2/5 by exp(1-k)>=2-k. Because C m-3/2<0, equation(7) gives
 sum E_i/H <=9/10+p+(12/25)m-(p-1/2)_+(p+1/2)
           <=69/50+(13/25)p-(p-1/2)_+(p+1/2)
           <=41/25.
The last expression is increasing up to p=1/2 on[0,1/2], and on[1/2,1] its deficit from41/25 is(p-1/2)(p-1/50)>=0. Finally1<k=p+C m<=C(p+m)=C f, so f>1/C>5/6. Hence
 sum E_i/F <(41/25)(6/5)=246/125.                                      (8)

7. CONCLUSION/SCOPE.
The four exhaustive regions K<=H; P>=H; P<H<K with F=H; and P<H<K with F<H give factors below9/5,7/4,157/80,246/125 respectively. Thus246/125 is a single valid uniform factor if the proof survives audit. No owner splitting, restricted family, finite report grid or changing ownership is invoked. This is an existence/payment-rule theorem for a supremum-defined mechanism; efficient computation of that supremum is NOT proved. The previously disproved nested rule is not claimed truthful. Novelty and specialist significance remain unassessed.
