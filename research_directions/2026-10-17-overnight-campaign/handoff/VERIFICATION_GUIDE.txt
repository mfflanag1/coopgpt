CURATED REPRODUCIBILITY GUIDE
17 October2026. Finite certificates and tests supplement conventional proofs.

QUICK START
Use Python3.10 or newer with assertions enabled; this campaign validated3.15.0. No third-party packages, solver, model,
network access or installation is needed for these curated26 entry points.
From the campaign directory, run:

 python3 -I handoff/replay_curated.py --report checks/LOCAL_CURATED_REPLAY.json

The runner copies the code/data into a temporary directory and executes there,
so checker-generated JSON does not overwrite archived research evidence.
Only the explicitly requested report path is written outside that disposable
copy. The report includes every command's scope, exact-vs-floating label,
stdout/stderr, hash of the executed copy taken before execution, timing and exit status. It does not verify proofs.
Use --only followed by manifest IDs for a focused replay, for example:

 python3 -I handoff/replay_curated.py --only pair_lower square_price_lower square_price_upper

Manifest: handoff/CURATED_CHECKS.json. Run without python -O: many exact
certificates deliberately use assertions. Isolated mode -I also prevents
PYTHONOPTIMIZE or unrelated user-site packages from changing the check.
