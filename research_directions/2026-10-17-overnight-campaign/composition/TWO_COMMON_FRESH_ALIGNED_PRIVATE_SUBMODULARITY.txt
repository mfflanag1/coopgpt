ALIGNED COMMON-RESOURCE PROFITS RESTORE PRIVATE DIMINISHING RETURNS
17 October 2026. New structural subcase; full mixed-owner mechanism remains open.
Historical novelty unconfirmed. Fractional-knapsack duality is an established
input; the private price selector and contract consequence are derived here.

MODEL
For any finite number M of activities, let a_j,b_j>0 and let their public
profits satisfy w_j=u a_j+v b_j for fixed u,v>0. Production is

 F(P,Q,c)=max sum_j w_j x_j,
   a.x<=P, b.x<=Q, 0<=x<=c.

Actual owner identities and eligible rows are fixed. Fix P,Q while allowing
arbitrary private capacity profiles c. The theorem allows M and the number
of actual private owners to be arbitrarily large. Common-resource reports
are fixed for the incentive statement below; no full mixed-owner/all-report
TCWM theorem is claimed.

THEOREM
For fixed common capacities, F is diminishing-returns submodular in the
private capacities: for c<=d and delta>=0,

 F(c+delta e_j)-F(c) >= F(d+delta e_j)-F(d).

There is an explicit, nonnegative, coordinatewise antitone private supporting
price selector g(c). Its uniform radial average

 pi_j(c)=integral_0^1 g_j(t c)dt

is coordinatewise antitone, nonnegative, and satisfies c.pi(c)=F(P,Q,c).
Paying each actual private-only owner its own reported private bundle
against pi is TCWM under arbitrary coalition restorations of private rows,
with common reports fixed. This is an exact private-block allocation of F,
not by itself a coalition-covering mechanism for the full production game.

1. NORMALIZATION AND DUAL FORMULA
Replace P,Q by uP,vQ and a,b by ua,vb. This positive public row scaling
preserves actual ownership, feasible reports and production, so assume
w_j=a_j+b_j. Put T=P+Q and W(c)=w.c. Let K_P(P,c) be the one-constraint
fractional knapsack value using only a.x<=P, and define K_Q analogously.
Then

 F(P,Q,c)=min{T,K_P(P,c),K_Q(Q,c)}.                     (1)

To prove (1), the private-price dual is

 min_{p,q>=0} Pp+Qq+sum_j c_j(w_j-a_jp-b_jq)_+.

An optimum with p,q>0 has both common constraints tight in every compatible
primal optimum, by complementary slackness. Since w=a+b, that optimum has
value P+Q=T. An optimum on an axis gives K_P or K_Q. Conversely each of
these three values is a feasible dual value: use its one-constraint dual,
or p=q=1 and private prices zero. An optimum exists for positive P,Q; zero
common capacities give F identically0; explicitly set g=pi=0 there.

2. THE ONLY BELOW-CEILING BRANCH TIE IS THE ALL-CAPS-FIT REGION
Suppose K_P(c)=K_Q(c)=F(c)<T. Choose the smallest optimal one-dimensional
common prices p_*(c),q_*(c). If both were positive, averaging the two optimal
dual solutions would give an optimal dual with p,q>0, forcing F=T, a
contradiction. If p_*=0, then K_P=W(c). Equality K_Q=W(c), with strictly
positive profits, implies that every private cap can be filled under Q:
b.c<=Q, so q_*=0 is available. Similarly a.c<=P. The other case is symmetric.
Thus a below-ceiling tie implies both common constraints accommodate all
private caps and both smallest prices are zero.

For one-dimensional fractional knapsack, p_*(c)>0 exactly when a.c>P.
Moreover p_*(c) is coordinatewise nondecreasing in c. One elementary proof
uses the dual objective J_c(p)=Pp+sum_j c_j(w_j-a_jp)_+: increasing any c_j
adds a nonincreasing function of p, so the smallest minimizer cannot move
left. Equivalently, sort the public profit-per-a ratios w_j/a_j; the
smallest optimum is their capacity-clearing threshold, and increasing
available capacities cannot lower that threshold. The same facts hold for q_*.

3. AN ANTITONE SUPPORTING PRICE SELECTION
Define g(c) as follows:

 - if F(c)=T, set g=0 (the private part of p=q=1);
 - if F(c)=W(c)<T, set g=w (the private part of p=q=0);
 - otherwise the active branch in (1) is unique. On the P branch set
   g_j=(w_j-a_j p_*(c))_+; on the Q branch use q_* and b_j.

These are valid private supergradients, with 0<=g<=w.
We now prove c<=d implies g(c)>=g(d), coordinatewise. The plateau case
F(c)=T stays on the plateau by monotonicity, and the all-caps-fit case has
g(c)=w, which dominates every possible later selected gradient.

Otherwise suppose c is on the P branch. Then a.c>P, so along the increasing
segment c(s)=c+s(d-c), a.c(s)>P: P scarcity cannot disappear. A switch to the
Q branch below the ceiling would, by continuity, pass through a tie of the
two branches. Section2 says such a tie requires all private caps to fit,
contradicting a.c(s)>P. Therefore the P branch persists until the ceiling is
reached; its smallest price p_* cannot decrease, so all selected g_j cannot
increase. After the ceiling they are zero. The Q case is symmetric.
This establishes antitonicity globally, including transitions through the
zero-common-price region. Integrating g_j on coordinate segments proves the
stated diminishing-returns inequality. Ties cause only finitely many affine
pieces; the selected supporting gradient agrees with directional derivatives
almost everywhere on each segment.

4. ACTUAL-OWNER CONSEQUENCE FOR PRIVATE RESTORATIONS
The antitone price selector remains antitone after the fixed radial integral.
The one-dimensional fundamental theorem along t c gives

 c.pi(c)=integral_0^1 c.g(t c)dt=F(P,Q,c)-F(P,Q,0)=F(P,Q,c).

Fix any actual coalition S of private-only owners, with aggregate reported
private bundle a and fixed outsiders' private bundle o. Its total payment is

 Y_S(a)=a.pi(a+o)=F(P,Q,a+o)-o.pi(a+o).

Under a nonnegative restoration to S, the first term is nondecreasing and
the subtracted term is nonincreasing. Thus Y_S is nondecreasing. This works
for every finite actual owner population, arbitrary private-row mixtures,
and every private report profile; it does not split or merge actual owners.

5. WHY THIS DOES NOT YET SOLVE THE FULL PROBLEM
The private prices can decrease when common resources are restored, so
common-owner compensation remains essential. Exact example: a=(1,1,1/4),
b=(1,1/4,1), w=a+b, private c=(1/4,4,1), Q=1. Increasing P from1 to2 gives

 pi(P=1)=(7/9,5/18,25/36),
 pi(P=2)=(8/9,5/9,5/9).

The third private owner's payment drops5/36. This alone is not an incentive
violation, because the P restorer need not belong to that private-only
coalition; it identifies the compensation needed when those owners collude.
Simply averaging the common dual prices along the same private ray fails
own-report monotonicity. Paying each common row a total F also fails for
sufficiently tilted coefficients; numerical/exact scouts are retained as
unpromoted falsifications of those candidate completions.

The theorem is therefore a constructive structural reduction on an unbounded
class. It closes the private-report obstacle for aligned profits and leaves
precisely common-report/mixed-owner compensation. It makes no claim of a
ratio-independent full-domain funding constant or an unrestricted lower.
