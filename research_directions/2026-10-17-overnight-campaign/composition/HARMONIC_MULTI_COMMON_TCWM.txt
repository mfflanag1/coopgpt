HARMONIC COMMON-RESOURCE COMPOSITION AND INTERACTING DEMAND TYPES
17 October 2026. Frozen TCWM-only structural theorem; novelty unconfirmed.

MODEL A: ONE PUBLIC DEMAND TYPE, MANY PRIVATE BRANCHES
There are t>=1 shared resource rows P_1,...,P_t, k>=1 private rows x_jl for each
of M>=1 activities, and fixed positive shared coefficients a_1,...,a_t. Activityj
consumes a_v units of shared row v and one unit of every private row x_jl, earns
one unit, and private rows are exclusive to that activity. Thus
 F(P,x)=min(min_v P_v/a_v, sum_j min_l x_jl).                 (1)
Actual owners can hold arbitrary fixed mixed bundles across all rows; their
binding underreports are coordinatewise. A min of aggregate shared capacities
is NOT treated as an additive virtual owner resource. The following price rule
works directly with the original actual shared-resource owners.

THEOREM A.
Let alpha=(k-1)/k and A_k=k/(k+1)^(1+1/k). For any fixed public C>=1 there is
nonnegative coalition-covering all-profile TCWM funding factor at most
 K(t,k,M,C)=max{tC+k, t+k A_k M^alpha/C}.                     (2)
For example C=max{1,sqrt((k A_k/t)M^alpha)} gives the simpler upper
 tC+max(t,k)=O_(t,k)(M^(alpha/2)).                           (3)
No full outside-production incentive or marginal-floor theorem is claimed.

1. HARMONIC AGGREGATE AND PRICES
When all shared capacities are positive, define
 Q=(sum_v a_v/P_v)^(-1),
 g_j=min(Q/C,x_j1,...,x_jk), G=sum_jg_j, r=Q/G,
 h=min(1,C/r), f=min(1,A_k(r/C)^(1/k)).                       (4)
Use shared prices p_v=h Q/P_v and private prices p_jl=f g_j/x_jl. Actual owneri
receives its reported bundle dotted with these common prices. If a required
shared capacity is zero, or G=0, all payments are zero. Zero private contributions
are zero. The coefficient a_v appears in Q, not as an extra factor in p_v.
Consequently sum_v a_v p_v=h exactly, as required by the activity dual.

We have Q<=min_v P_v/a_v, G<=MQ/C, r>=C/M, and
 F>=min(Q,G).                                               (5)
Total payment is exactly tQh+kGf: each positive shared resource contributes Qh.

2. COVERAGE
If r<=C, h=1 and sum_v a_v p_v=1, so shared prices alone cover every activity.
If r>C, G<Q/C and no private branch is capped; then g_j=min_l x_jl and each
supported branch has sum_l g_j/x_jl>=1. The established scalar inequality
h+f>=1 proves every supported activity's dual constraint. Hence every actual
owner coalition receives at least its own production value. This is coverage
for F in(1), not merely for a smaller harmonic proxy.

3. DIRECT FIXED-OWNER TCWM PROOF
For a coalition aggregate s<=c, with outsiders fixed, define
 Z_P=Q sum_v s_v/P_v, Z=sum_j g_j sum_l s_jl/x_jl.
Its payment is Y=h Z_P+f Z, with0<=Z<=kG. As before h_r<=0,f_r>=0,
h+r h_r>=0 and f-k r f_r>=0.

If a private coordinate restores, Q and Z_P stay fixed. The private derivative
satisfies Z'>=G'>=0, while r'=-rG'/G. Thus
 Y'=h_r r' Z_P+f_r r'Z+fZ'>=(f-k r f_r)G'>=0.               (6)

If shared coordinate P_v restores, its coalition coordinate s_v increases at
the same rate1. Then
 Q'=a_v Q^2/P_v^2>=0,
 Z_P'=(Q'/Q)Z_P+Q(P_v-s_v)/P_v^2 >=(Q'/Q)Z_P.                (7)
If u branches are capped at Q/C, G'=u Q'/C and Z'>=0. Because G>=u Q/C,
 0<=r'=Q'(G-uQ/C)/G^2 <=r Q'/Q.
Therefore
 Y'=h_r r'Z_P+h Z_P'+f_r r'Z+fZ'
    >=(Q'/Q)Z_P(h+r h_r)>=0.                               (8)
This is the load-bearing harmonic identity. It preserves original mixed-owner
shares and does not assume an additive ownership map through Q.

Along a single-coordinate path Q is rational on positive shared support, each
minimum has finitely many switching points, and h/f crossings are finite unless
identical, so the regular derivative argument extends by continuity. Private
terms vanish continuously at zero rows. As any required shared capacity tends
to0, Q tends to0; the funding bound below and F<=P_v/a_v force nonnegative
payments to0. At G tending to0 with positive Q, total payment=(tC+k)G tends to0.
Thus zero faces and all finite coordinate/whole-bundle restorations are included.

4. FUNDING
If r<=1, F>=Q and h=1, giving
 total/F<=t+kf/r<=t+k A_k M^alpha/C.
If r>1, F>=G and total/F<=t r h+kf<=tC+k. This proves(2).
Choosing C in(3) gives the stated bound by direct substitution. The exponent
asymptotics hold for fixed t,k; explicit formulas should be retained if t grows.

MODEL B: GENUINELY INTERACTING PUBLIC DEMAND TYPES
There are L shared resource rows and finitely many public activity types T.
Type tau has a fixed nonnegative demand vector a^tau, with nonempty support
S_tau subset of the shared rows. Every activity of that type uses this shared
vector and its own k private rows. Private rows remain exclusive to each activity.
Types may overlap in shared rows, and their demand vectors need not be collinear.
Actual shared resources are simultaneously consumed by all types in the true LP.
Private coefficients may be arbitrary positive public constants, handled by fixed
owner-preserving row rescaling. Public activity profits may differ within a type.

THEOREM B: TYPE CONGESTION TRANSFER.
For each type, choose a valid funding bound K_tau for its isolated type game
F_tau using TheoremA and its public-profit layer corollary below. Pay the sum of
these mechanisms on the SAME actual-owner reports. Define
 D=max_{shared row v} sum_{tau:v in S_tau} K_tau.              (9)
Then the sum mechanism is coalition-covering, nonnegative and all-profile TCWM
for the true interacting production LP, with total payment at most D F_true.
For fixed L and a fixed number of public demand types, its rate is
O_(L,T,k)(M^((k-1)/(2k))) independent of actual-owner count. In particular k=1
has a constant bound even with arbitrarily many activities, unlike the rank3
common-cap family having two private complementary rows per activity.

Proof of coverage. Relaxing competition between types can only increase value,
so F_true(S)<=sum_tau F_tau(S) for every actual-owner coalition. Typewise coverage
therefore implies actual coverage. Fixed positive sums preserve every TCWM
inequality, with all owner identities unchanged.
Proof of funding. Take an optimal plan for each isolated type. Multiply its
activity quantities by K_tau/D and combine the resulting plans. In shared rowv,
type tau used at most P_v alone, so combined use is at most
 P_v sum_{tau:v in S_tau}K_tau/D<=P_v.
Every private row belongs to one type, and K_tau<=D because S_tau is nonempty,
so its scaled plan remains feasible. Thus the combined plan is feasible in the
true LP and has value(sum_tau K_tau F_tau)/D. Therefore
 sum_tau K_tau F_tau<=D F_true,
which bounds the actual total payments. This argument works for arbitrary
public profits and heterogeneous type vectors, not only unit coefficients.
It is a feasible time-sharing comparison, not an exact value decomposition.

WITHIN-TYPE HETEROGENEOUS PROFITS
For fixed type tau, sort its public profits after any activity normalization.
The isolated type only has the common throughput bound min_v P_v/a_v^tau;
its private branch caps q_j=min_l x_jl are independent. Hence the elementary
fractional-knapsack identity gives a fixed positive sum of prefix games, each
again of form(1). Apply TheoremA to each prefix and sum; use the maximum bound
for M_tau branches. This step is an established greedy/layer ingredient, not
asserted as a new representation theorem. Noncollinear different types are
combined by TheoremB's inequality, not falsely by that exact layer identity.

LIMITATIONS AND MATHEMATICAL CONSEQUENCE
This is a multi-resource composition result with direct mixed-owner incentive
proof and a checked type-congestion loss. It does not establish a bound independent
of the number of arbitrary continuously varying demand vectors. Counting every
activity as a new type can give a linear loss and does not solve that frontier.
The harmonic map is nonlinear in actual capacities; no outside-production
inequality is inferred from the TCWM proof. Arbitrary private-row sharing between
activities also lies outside the stated model. The theorem is a structural advance
beyond one-common-resource exact layering, not a claim of novelty or a complete
infrastructure economic model.
MATCHING FIXED-t,k EXPONENT. For k>=2, duplicate every power owner's
capacity and each of its allowed reports identically across the t normalized
common rows P_v/a_v. On this fixed linear embedded subdomain, all coalition
values and all whole-bundle report comparisons are exactly those of the
one-common technology. Any full-domain mechanism restricts to a mechanism
there with the same funding factor. The one-common lower therefore gives
Omega_k(M^((k-1)/(2k))), matching the displayed upper exponent for fixed t,k.
