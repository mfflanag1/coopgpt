EXACT RATIONAL WEIGHTED MECHANISM REPLAY

weighted_graph_mechanism.py exposes weighted_prices(capacities,edges,profits)
and payments(owner_bundles,edges,profits). It uses only Python standard-library
Fraction arithmetic and the exact_huber_solver.py in this same folder.
The CLI accepts one JSON file with owner_bundles, edges, profits; use integer
JSON numbers or rational strings such as "3/2", not binary floating-point
approximations when exact intended decimal/rational values matter.

Each reported original bundle is copied by the fixed public graph unfolding.
The returned original-resource prices, actual-owner payments, production,
and funding are exact rationals. A unit-lift KKT/primal-dual certificate is
included. Zero-profit technology and all-zero report profiles are handled.
The default explicit copy limit is100,000, to reject accidental enormous
expansions; it does not turn the pseudo-polynomial algorithm into a polynomial
one in the original binary input length.

 python3 -I check_weighted_graph_mechanism.py
