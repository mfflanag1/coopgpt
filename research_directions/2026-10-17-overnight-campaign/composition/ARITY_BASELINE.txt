ARITY BASELINE FOR GRAND-MARGINAL FUNDING
17 October 2026. Rediscovered established baseline, not a new result.

PRIORITY CORRECTION: Root located the existing project statement in
research_directions/2026-10-11-ai-infrastructure/SPARSE_PRODUCTION_NOTE.txt,
including its MPH-r connection and Ezra et al. arXiv:1811.09871, Lemma 6.2.
The independent proof below is retained as an audit aid only.

Fixed finite actual owners report divisible stocks b_iv >= 0 in resource rows v.
An activity uses fixed nonnegative coefficients in at most r resource rows,
and earns a fixed nonnegative linear value. Activities can overlap and the
resource graph need not be a forest. An owner may supply any fixed bundle.
F(b) is the optimum of the resulting continuous packing LP. Underreports bind;
owner utility is payment only. Assume finite attained optimum (automatic for
the finite unit-production graph model after discarding zero-use activities).

THEOREM. U_i(b) = F(b) - F(b_{-i}) is coordinatewise own-report monotone,
covers all actual-owner coalitions, and sum_i U_i(b) <= r F(b).
In particular all unit-production resource graphs admit factor two. This is
only the baseline; the campaign asks for a uniform strict improvement on forests.

Coverage: a nonnegative optimal dual row-price vector p gives
F(b) = sum_i p.b_i and F(b_{-i}) <= sum_{j != i} p.b_j. Hence U_i >= p.b_i.
For every S, sum_{i in S} U_i >= p.sum_{i in S} b_i >= F(b_S), by dual
feasibility. If a dual optimizer is unavailable under a broader formulation,
epsilon-optimal dual prices and a limit prove the same inequality.

Arity bound: fix one optimal activity vector x. Disaggregate the consumption
in each resource row among owners, respecting each reported stock. For every
activity e of output x_e, couple its owner-assignment marginals across its at
most r required rows. For instance take the independent product coupling.
This splits e into finitely many owner-labelled variants, each with the same
value per output unit and supported by a set S of at most r actual owners.
The total value of the variants is exactly F(b), and their resource usage by
owner is feasible. Delete every variant whose support contains i. The rest is
feasible without owner i, so U_i is at most the deleted value. Summing in i
counts each variant's value exactly |S| <= r times, proving the bound.

Own-report monotonicity is immediate: the first term increases and the second
term excludes i and is fixed. Nonnegativity follows from free disposal.
No cloning is strategic: labelled variants only decompose a single primal
allocation. The owner set, reports and eligible deviation boxes remain fixed.

REFINEMENT. For the chosen optimal labelled allocation, let W_s be its value
supported by exactly s actual owners. Then sum_i U_i <= sum_s s W_s. For
pairwise activities this is 2F - W_1. Thus any theorem forcing a positive
fraction of optimum value to be internally owner-supported immediately beats
two for this rule. Arbitrary mixed ownership does not force that fraction.

STATUS. Analytic derivation recorded for independent review. This is a direct
bounded-arity packing observation; no novelty claim. It does not resolve the
strict-below-two target, nor the unrestricted dimension/owner-count gap for
production with unbounded arity.
