PUBLIC HETEROGENEITY ON THE COMMON-RESOURCE HYPERSTAR
17 October 2026. Corollary candidate; the layer/greedy ingredient is established
mathematics, not asserted as a new reduction. Historical novelty of the combined
incentive theorem remains unconfirmed.

MODEL
There are M activities. Activity j consumes alpha_j>0 units of a common resource
P and beta_jl>0 units of each of k private resources c_jl, used only by activityj;
it earns public nonnegative value w_j. All coefficients and values are fixed,
public and independent of reports. Actual owners hold arbitrary fixed mixed
bundles across common and private resource rows. Production is the continuous LP
 F(P,c)=max sum_j w_j x_j
 subject to sum_j alpha_j x_j<=P, beta_jl x_j<=c_jl, x_j>=0.    (1)

THE COROLLARY
The common-cap mechanism in COMMON_CAP_GENERAL_ARITY_RATE.txt extends to(1)
with exactly the same funding upper
 k+max{1,k/(k+1)^((1+1/k)/2) M^((k-1)/(2k))},                 (2)
independent of coefficient ratios, owner count and report profile, while
preserving nonnegative payments, coalition coverage and whole-bundle TCWM.
A finite sum of at most M public layers suffices. Unit coefficients/values are
a subclass, so for each fixed k>=2 the optimal uniform rate over this model is
still Theta_k(M^((k-1)/(2k))). No empirical performance or private-cost claim is
made; all value and technology coefficients are public here.

1. FIXED OWNER-PRESERVING RESCALING
Set z_j=alpha_j x_j, v_j=w_j/alpha_j and
 b_jl=(alpha_j/beta_jl)c_jl, q_j=min_l b_jl.
Then
 F(P,c)=max{sum_j v_j z_j:sum_j z_j<=P,0<=z_j<=q_j}.           (3)
Each actual owner's holding in private row j,l is multiplied by the same fixed
positive alpha_j/beta_jl. This map is additive across actual owners, preserves
coordinatewise binding underreports and coalition capacities, and introduces no
new owner or resource entitlement. P remains with its original actual owners.

2. EXACT PUBLIC VALUE LAYERS
Sort public values v_(1)>=...>=v_(M)>=v_(M+1)=0, breaking ties by any fixed rule.
Let S_l denote the first l activities. The fractional-knapsack value(3) obeys
 F(P,c)=sum_{l=1}^M (v_(l)-v_(l+1))
               min(P,sum_{j in S_l} q_j).                   (4)
Equivalently F=int_0^infinity min(P,sum_{j:v_j>=t}q_j)dt.

An elementary proof avoids importing any unverified representation theorem.
For any feasible z, summation by parts gives
 sum_j v_j z_j=sum_l (v_(l)-v_(l+1))sum_{j in S_l}z_j
 <=sum_l (v_(l)-v_(l+1))min(P,sum_{j in S_l}q_j).
The greedy plan fills activities in nonincreasing v order until either capacity
P or all q_j are exhausted. Every prefix receives exactly min(P,prefix total q),
so it attains equality simultaneously in every term. This proves(4) for every
real nonnegative capacity vector, including zeros, and therefore separately for
every actual-owner coalition's aggregate capacities.

3. FIXED-POSITIVE-SUM TRANSFER
For each nonzero public coefficient v_(l)-v_(l+1), run the unit common-cap
mechanism on S_l and P, with exactly the original actual owners holding their
rescaled coordinates. Owners not supplying a layer's resources remain the same
actual owners with zero holdings in that layer; no identity changes during a
deviation. Sum the layer payments with these fixed nonnegative coefficients.
Each layer is all-profile TCWM for every coalition, so the positive sum is too.
Coverage sums to the coalition's exact value by(4). Funding is at most
 sum_l weight_l K_(k,l) F_l <=K_(k,M)sum_l weight_l F_l
 =K_(k,M) F,
because the established upper K_(k,l) in(2) is nondecreasing in l. Alternatively
use the common public C chosen for M in all layers; its funding bound remains
valid because each layer has at most M branches. All coalition inequalities use
the same fixed public layers and same owner mapping at every report profile.

4. BOUNDARIES
Private resource rows are branch-specific; sharing additional private rows
between different activities invalidates the fractional-knapsack reduction.
The common-resource coefficients must be positive for the displayed rescaling.
Zero-profit activities can be discarded. Branches with no private resource or
zero common-resource consumption need separate treatment and are not silently
included in this corollary. Integral jobs, deadlines, private opportunity costs,
network losses and strategic reports of the technology coefficients are outside
the stated domain. The result permits heterogeneous public value and power use,
but a credible infrastructure application still needs an explicit ownership and
deviation interpretation; no measured gains follow from this theorem alone.
