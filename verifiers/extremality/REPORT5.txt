WHY THE TWO RIGID FAMILIES ARE PLAUSIBLE (sketch, not a proof).  Write
v(X) = min_j g_j(X ∩ B_j); since g_j vanishes off B_j, v(X) = 0 unless X meets
every block, so the only active constraints come from transversal-ish sets.
When at most one block B_1 has size >= 2, every other block is a singleton
{p_j} with g_j(p_j) = T, so v(X) = g_1(X ∩ B_1) whenever X contains all those
singletons and 0 otherwise; taking X = (N \ B_1) ∪ (B_1 \ {i}) gives the caps
x_i <= g_1(i) for i in B_1, and the core collapses to a one-block problem.
When every block has size <= 2 the transversal constraints are pairwise and
the same collapse happens blockwise.  A third block of size >= 2 alongside a
block of size >= 3 is what first gives the two selections room to disagree --
the size-3 block supplies an interior player the floor can raise while the
size-2 block supplies the cap the ceiling must respect.  I did not complete a
hand proof of either direction and am not claiming one.

LEMMA (dual description of the core; verified, proof three lines).
Let the blocks be B_1..B_k, let w_i = g_{j(i)}(i) be player i's weight in its
own generator, so w(B_j) = T for every j, and write w(A) = sum_{i in A} w_i.
Then
        v(X) = min_j  w(X n B_j)                                        (V)
and, writing rho(A) = max_j w(A n B_j),
        Core(v) = { x >= 0 : x(N) = T,  x(A) <= rho(A) for every A }.   (C)

PROOF.  (V): g_j vanishes off B_j, so g_j(X) = w(X n B_j), and v is the lower
envelope.  (C): for proper X, max_j w((N\X) n B_j) = max_j (T - w(X n B_j))
= T - min_j w(X n B_j) = T - v(X), so given x(N) = T the core inequality at X
is exactly the cap at A = N \ X.  Nonnegativity is the singleton case, since
v({i}) = 0 once k >= 2.                                                  []

VERIFIED: (V) and the cap identity checked exactly on 26 block games spanning
the profiles (3,2,1), (2,2,2), (4,1,1), (3,3,1), (2,2,1) -- zero failures.

WHY THIS IS THE RIGHT STARTING POINT.  It turns the class into a pure system of
UPPER CAPS -- the exact analogue of paper5's thm:duality for the two-generator
class -- and it makes the pairwise structure visible: for u, v in DIFFERENT
blocks, A = {u,v} gives
        x_u + x_v  <=  max(w_u, w_v),
which is far stronger than the within-block caps x(A) <= w(A).  The
cross-block caps are what the two selections have to negotiate, and the
conjunction condition (a block of size >= 3 AND another of size >= 2) is
plausibly the smallest configuration in which that negotiation has two
degrees of freedom pulling opposite ways.  I did not turn this into a proof.

A TRAP, RECORDED SO THE NEXT ATTEMPT DOES NOT LOSE A DAY TO IT.
The cap form (C) invites a polymatroid argument: a polytope
{x >= 0 : x(A) <= rho(A)} equals P(rho^) for the Dilworth truncation rho^,
which is submodular; rho^(N) = T here (every partition of N has
sum_i rho(A_i) >= sum_i w(A_i n B_1) = T, with equality at the trivial
partition), so Core(v) looks exactly like the BASE POLYTOPE of a polymatroid.
On base polytopes the decreasingly-minimal and increasingly-maximal elements
coincide (Fujishige's lexicographically optimal base / the Frank--Murota
dec-min theory), which would give Lmin = Lmax for EVERY profile.

That conclusion is FALSE -- the audited (3,2,1) witness has rho = 1/3.  So one
of the steps is wrong, and I could not determine which within this round.  The
candidates are (i) Core(v) is not in fact the base polytope of rho^ (the
truncation may not be attained where the argument needs it), or (ii) the
dec-min = inc-max identity does not apply in the form recalled here, e.g. it
needs integrality or an M-convexity hypothesis this polytope lacks.  Either way
the route is NOT usable as stated, and anyone who reaches for it from the cap
description -- which is the natural next thought -- should settle (i) versus
(ii) FIRST, on the (3,2,1) witness, before building on it.  Flagged rather than
resolved; asserting either branch without checking is exactly the kind of
plausible-and-wrong step this campaign keeps catching.

    = rho^(A) for all 62 proper A, where rho^ is the partition-truncation of
    rho computed by the split recursion), and rho^(N) = T;
  * but rho^ is NOT SUBMODULAR.  Witness, hand-checkable on the blocks
    {1,2,3}/{4,5}/{6} with weights (1,4,1)/(1,5)/(6):
        A = {1,4}, B = {2,4}:   rho^(A u B) + rho^(A n B) = 5 + 1 = 6
                                rho^(A)     + rho^(B)     = 1 + 4 = 5.
So the failing step is the one I suspected first: Core(v) is NOT a polymatroid
base polytope.  My claim that {x >= 0 : x(A) <= rho(A)} = P(rho^) with rho^
submodular was simply wrong -- the Dilworth truncation is submodular for
INTERSECTING-submodular inputs, not for an arbitrary monotone rho, and this rho
is not intersecting-submodular.  There is therefore no tension with Fujishige
or Frank--Murota at all; they never applied.  The route is dead for a clean
reason rather than merely unusable, and nobody needs to re-derive this.

--------------------------------------------------------------------------------
PROPOSITION (rigid direction, case (a)).  If at most one block has size >= 2,
then Lmin(v) = Lmax(v).
--------------------------------------------------------------------------------
PROOF.  Let B_1 be the only block that may have size >= 2; every other block is
a singleton {p} with w_p = w(B_j) = T.

STEP 1: the core is a CAPPED SIMPLEX,
        Core(v) = { x >= 0 : x(N) = T,  x_i <= w_i for i in B_1 }.
By the dual description (C), Core(v) = {x >= 0 : x(N)=T, x(A) <= rho(A)}.  If A
meets a singleton block {p} then rho(A) >= w_p = T, and rho <= T always, so the
cap at A reads x(A) <= T, which x >= 0 and x(N) = T already give.  If A is
contained in B_1 then rho(A) = w(A), and x(A) <= w(A) follows by summing the
singleton caps x_i <= w_i, which are themselves the caps at A = {i}.  So the
caps on B_1's singletons are the only binding ones.

STEP 2: on a capped simplex both selections are the same water-filling point.
Write c_i = w_i for i in B_1 and c_i = T otherwise, and let theta be the unique
solution of sum_i min(c_i, theta) = T; put x*_i = min(c_i, theta).
  Lmax.  If a feasible x has max_i x_i <= M then T = sum_i x_i <= sum_i
  min(c_i, M), so M >= theta; and x* attains max = theta.  So theta is the
  minimum possible maximum, and x* attains it.
  Lmin.  If a feasible x had min_i x_i > theta then T = sum x_i > n*theta,
  while sum_i min(c_i,theta) = T with every term <= theta gives T <= n*theta --
  a contradiction.  So min_i x_i <= theta; also x_i <= c_i gives min_i x_i <=
  min_i c_i.  Hence min_i x_i <= min(min_i c_i, theta) = min_i x*_i, and x*
  attains it.  So x* maximizes the minimum.
Each selection then pins the coordinates achieving its extreme level and
recurses on the remaining players, which is again a capped simplex with the
same data; the recursion produces x* at every stage on both sides.  Hence
Lmin = Lmax = x*.                                                          []

  VERIFIED (mechanism, not just conclusion): 36 random case-(a) instances at
  n = 5,6,7 -- in every one Lmin = Lmax AND both equal the water-filling point
  min(c_i, theta).  Zero failures.  Note this covers the profiles (6,1,1),
  (5,1,1), (4,1,1), (3,1,1) and all the all-singleton ones, i.e. exactly the
  rigid profiles of the second clause.

B2.  THE REDUCTION THAT DOES HOLD WHEN ALL BLOCKS ARE <= 2
--------------------------------------------------------------------------------
LEMMA.  If every block has size <= 2 then the binding caps are exactly the
PARTIAL TRANSVERSAL caps:
        Core(v) = { x >= 0 : x(N) = T,  x(A) <= max_{i in A} w_i
                    for every A meeting each block at most once }.
PROOF.  From the dual description, the cap at A is x(A) <= rho(A)
= max_j w(A n B_j).  If A contains a whole block then rho(A) = T and the cap is
implied by x >= 0 and x(N) = T.  Otherwise A meets each block at most once
(blocks have size <= 2), so w(A n B_j) is either 0 or a single weight, and
rho(A) = max_{i in A} w_i.                                                 []
The |A| = 1 case is the singleton cap x_i <= w_i; the |A| = 2 cross-block case
is x_u + x_v <= max(w_u, w_v), the constraint I identified as the obstruction
to case (a)'s argument.  So the whole system is now explicit.

B3.  THE MECHANISM, IDENTIFIED AND VERIFIED (not proved)
--------------------------------------------------------------------------------
TRANSVERSAL WATER-FILLING: raise all free players together until some partial
transversal cap saturates; freeze that transversal's players at that level;
repeat on the rest with the residual budget.
VERIFIED: on 40 instances over the profiles (2,2,2), (2,2,1,1), (2,2,2,1) and
(2,2,2,2) -- the last at n = 8, so the check is dimension-crossing -- the
greedy point equals Lmin AND equals Lmax, 40/40.  This is the same standard as
case (a): the MECHANISM is verified, not merely the coincidence.
WHAT IS MISSING: a proof that each selection must equal this point.  For case
(a) that step was two short arguments because the feasible set was a capped
simplex and the bound on max (resp. min) was immediate.  Here the saturating
object at each stage is a transversal rather than a coordinate, and I do not
have the corresponding two bounds.  That is the blocker, and it is now a
precise one: show (i) any feasible x has max_i x_i >= the greedy's first level,
and (ii) any feasible x has min_i x_i <= it.

B4.  NEGATIVE CONTROL -- WHERE THE ARGUMENT FAILS ON (3,2,1), VISIBLY
--------------------------------------------------------------------------------
The reduction B2 is exactly what a size-3 block destroys, and one can point at
the set.  On the audited witness (blocks {1,2,3}/{4,5}/{6}, weights
(1,4,1)/(1,5)/(6)), take A = {2,3}: two players of the size-3 block, so A does
NOT contain a whole block, yet
        rho(A) = 1 + 4 = 5   while   max_{i in A} w_i = 4.
The cap is x_2 + x_3 <= 5, not <= 4.  So the partial-transversal description --
the entire basis of B2 and hence of B3 -- is unavailable the moment one block
reaches size 3, and it fails on a two-element set one can write down.  This is
the requested visible failure point, and it also says why the two clauses of
the corrected condition are the right two: clause one bounds block size so that
each block contributes at most one player to any non-trivial cap; clause two
(at most one block of size >= 2) instead makes every cross-block cap vacuous.
Two different reasons, one boundary.

--------------------------------------------------------------------------------
B5.  THE TWO STAGE-ONE BOUNDS -- ONE PROVED EACH WAY; THE GAP IS NOW ATTAINMENT
--------------------------------------------------------------------------------
Write m(A) = max_{i in A} w_i, and let A range over PARTIAL TRANSVERSALS (at
most one player per block), which by B2 index exactly the binding caps.  Put
        theta1 = min( T/n,  min_A  m(A)/|A| )
        M*     = max( T/n,  max_{|A|<n} (T - m(A))/(n - |A|) ).

LEMMA (floor bound).  Every x in Core(v) has min_i x_i <= theta1.
PROOF.  Suppose min_i x_i > theta1.  If theta1 = T/n then x(N) > n*(T/n) = T,
contradicting efficiency.  Otherwise theta1 = m(A)/|A| for some partial
transversal A, and then x(A) > |A| * m(A)/|A| = m(A), violating the cap at A. []

LEMMA (ceiling bound).  Every x in Core(v) has max_i x_i >= M*.
PROOF.  If all x_i < T/n then x(N) < T.  And for any partial transversal A with
|A| < n, the cap gives x(A) <= m(A), so x(N\A) >= T - m(A) and some player of
the complement carries at least (T - m(A))/(n - |A|).                       []

VERIFIED TIGHT: on instances of (2,2,2), (2,2,1,1), (2,2,2,1) and (2,2,2,2),
min(Lmin) = theta1 AND max(Lmax) = M* in every case.

WHAT THIS CHANGES.  The blocker was "I have no bounds"; it is now the single
word ATTAINMENT, in two places, plus the recursion:
  (A1) exhibit a core point attaining min = theta1 (the uniform level theta1
       leaves T - n*theta1 to place without breaking a cap; plausible, unproved);
  (A2) exhibit a core point attaining max = M*;
  (A3) show each selection then pins the same set at that level, so that the
       recursion -- which is again a system of the same shape on the remaining players
       -- carries both to the same point.
(A1) and (A2) are what the transversal water-filling greedy of B3 does
constructively, 40/40; turning that construction into a proof of feasibility is
the remaining mathematical content.  Note the pleasant symmetry: the floor
bound comes from a cap read directly, the ceiling bound from the same cap read
on the complement -- which is exactly the "one inequality read twice" shape the
PART frame has, and is the first sign that case (b) has a clean proof at all.
