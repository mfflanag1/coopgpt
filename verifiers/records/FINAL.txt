================================================================================
ROUTE 1 — CAMPAIGN RECORD
The Lmin / Lmax separation in exact TU games
================================================================================
Companion files: THEOREMS.txt (Parts I-IV, full proofs), S5PROOF.txt (the n=5
upper bound), summary.json, summary2.json.  This file is the consolidated
ledger: what is proved, what is verified, what is open.

Notation.  n players, v singleton-normalized exact, T := v(N) > 0,
x := Lmin(v) (leximin core point), z := Lmax(v) (leximax-min core point),
rho(v) := ||x - z||_1 / T,  s(n) := sup rho over n-player games.
        f(S) := T - v(N\S),      mu := min_i x_i,     M := max_i z_i,
        lambda := min_{S != empty} f(S)/|S|,          nu := max_{S != empty} v(S)/|S|.

================================================================================
1.  HEADLINE
================================================================================
The conjecture under test, rho <= (n-4)/(n-2), is FALSE for every n >= 5.  So is
the first correction (n-4)/(n-3).  The truth is that rho is not bounded by any
constant below the trivial ceiling:

        s(n) >= 2 - 8/n   (n even),      2 - 8n/(n^2-1)   (n odd),
        sup_n s(n) = 2.

rho crosses 1 at n = 8: there is an 8-player exact game with
||Lmin - Lmax||_1 = v(N) exactly.  Asymptotically the two egalitarian selections
have disjoint supports: leximin concentrates essentially all of v(N) on one
player while leximax-min spreads it over about n/2 players.

================================================================================
2.  PROVED
================================================================================
P1.  CORE DUALITY (any game, any n).
        Core(v) = { x >= 0 : x(N) = T, x(S) <= f(S) for all S }.
     Because x(S) >= v(S) <=> x(N\S) <= T - v(S) = f(N\S), and S -> N\S is an
     involution on coalitions.  The two-generator version is the computation
     f(S) = max(g(S), h(S)); the duality itself needs no structure.
     [supersedes the paper's Theorem 11 statement]

P2.  SUPPORT DISJOINTNESS.  For a singleton-normalized two-generator game the
     supports A = {i : g_i>0}, B = {i : h_i>0} are disjoint and players outside
     A u B are null, so WLOG A u B = N.

P3.  BRACKETING.   mu <= lambda   and   M >= nu   (immediate from P1).

P4.  THE MASTER FAMILY G(p,k).  For p >= 1, k >= 2, n = p+1+k, T = pk:
        g = (p(k-1), 1^p, 0^k),      h = (0^{p+1}, p^k)
        Lmin = ( p^2(k-1)/(p+1), [p/(p+1)]^{p+k} )
        Lmax = ( p(k-1)/k, [1/k]^p, [p(k-1)/k]^k )
        ||Lmin - Lmax||_1 = 2p(p(k-1)-1)/(p+1),   rho = 2(p(k-1)-1)/(k(p+1)).
     Engine: the single cap f(O u {b}) = max(p,p) = p for every b in B (O = the
     p "ones"), so p+1 players share at most p.  Leximin reads it as a cap and
     is forced to floor p/(p+1), piling the residual on the head; leximax-min
     reads it as a budget and must squeeze every one down to 1/k.  ONE tight
     coalition drives the two selections to opposite corners.
     Core membership of both closed-form points is PROVED for all (p,k) by a
     four-case check on (eps, i, j) = ([head in S], |S n O|, |S n B|).
     Tight caps, identical for BOTH points: (T1) O u {b}; (T2) {head} u B' with
     |B'| = k-1; (T3) N.  At (T1) and (T2) the g-side and h-side of f tie.

P5.  DEFICIT IDENTITY.   2 - rho(G(p,k)) = 2n / (k(p+1)),  with k + (p+1) = n.
     So maximizing rho is maximizing a product of two integers of fixed sum n;
     the optimum is the balanced split k = ceil(n/2), p+1 = floor(n/2).

P6.  THE LOWER BOUND ON THE SUPREMUM (Section 1 headline), from P5, together
     with rho <= 2 always (both points nonnegative with equal totals).

P7.  THE n = 5 REFUTATION.  g1 = (1,0,0,1,2), g2 = (0,1,3,0,0), T = 4:
     Lmin = (1/2,1/2,5/4,1/2,5/4), Lmax = (1,0,1,1,1), rho = 1/2 > 1/3.
     Proved by hand from the four core vertices; the core is the affine slice
     x0 = x3 = s, x1 = 1-s, x2+x4 = 3-s.  No LP.

P8.  n = 5 CONFIGURATION RESULTS (S5PROOF.txt Part C).  In configuration CFG
     [Lmin strata (3,2); Lmax strata (1,4) with exactly one ZERO]:
       M = T/4;  the SIZE LEMMA f(S)/|S| >= T/8 for every S != {j};
       nu is attained off j with |S*| in {2,3};  mu <= T/6, and mu <= T/8 when
       |S*| = 3;  and ||Lmin - Lmax||_1 = T - 4 mu.
     Four-player rigidity is load-bearing here: it is what forbids |S*| = 4
     (else j is null, deletion leaves a 4-player exact game, Lmin = Lmax).

P9.  LP-DUALITY REDUCTION OF A3 (new, both sides).  Put h(S) := nu|S| - v(S) >= 0
     and f'(S) := f(S) - lambda|S| >= 0.  Then
        M = nu      <=>  every fractional cover w has  sum_S w_S h(S)  >= h(N),
        mu = lambda <=>  every fractional cover w has  sum_S w_S f'(S) >= f'(N).
     (Farkas on {x in Core, x <= nu*1} resp. {x in Core, x >= lambda*1}, then
     covering/packing duality.  w = 1_{S=N} always attains equality, so the only
     question is whether some OTHER cover strictly beats it.)

P10. BALANCED COVERS NEVER BEAT IT (both sides, any n).
     M-side: if w is balanced then sum w_S |S| = n, so
        sum_S w_S h(S) = nu*n - sum_S w_S v(S) >= nu*n - T = h(N),
     using sum_S w_S v(S) <= v(N) for balanced collections (valid because the
     core is nonempty: sum w_S v(S) <= sum w_S x(S) = sum_i x_i = T).
     mu-side: the complements of a balanced collection with weights w and total
     W form a balanced collection with weights w/(W-1), so
     sum_S w_S v(N\S) <= (W-1)T and sum_S w_S f(S) >= WT - (W-1)T = T = f(N).
     CONSEQUENCE: any failure of A3 needs a STRICTLY OVER-COVERING certificate.

P11. THE COVERING OBSTRUCTION (new, any n).  Let the nu-tight family be
     Tau_nu := { S : v(S) = nu|S| }.  If Tau_nu covers N and nu > T/n, then
     NO core point satisfies x <= nu*1, hence M > nu.
     PROOF.  Sum the core inequalities x(S) >= v(S) = nu|S| over a cover with
     weights w: with c_i := sum_{S ni i} w_S >= 1 this gives
     sum_i c_i (x_i - nu) >= 0.  If x <= nu*1 every term is <= 0, so x_i = nu
     for every covered i, i.e. for all i; then T = nu*n, contradicting
     nu > T/n.                                                              []
     Dually Tau_nu contains NO balanced subcollection unless nu = T/n (P10).
     So a failure of M = nu requires a family of nu-tight coalitions that
     covers N but contains no balanced subcollection.

P12. THE n = 6 MECHANISM, EXHIBITED.  For the smallest M-side counterexample
     (n = 6, T = 5, g = (3,2,0,0,0,0), h = (0,0,2,1,1,1), nu = 1, M = 6/5), the
     optimal cover is exactly of the type P11 describes:
        w = 1 on {2,3}, {1,3,4}, {1,3,5}, {1,3,6}   -- all four nu-tight, h = 0
        per-player excess (2,0,3,0,0,0)  -- strictly over-covering
        cover value 0  <  h(N) = 1.
     Player 2 lies only in {2,3}, which forces w_{23} = 1 and kills the other
     three in any balanced subfamily, leaving players 1,4,5,6 uncovered -- so no
     balanced subcollection exists, exactly as P11 requires.
     For the n = 5 extremal the optimal cover is BALANCED (excess all zero,
     value 1 = h(N)), so the criterion is not met and M = nu holds.

3.  VERIFIED, NOT PROVED (with counts; all exact rational arithmetic)
================================================================================
V1.  A3: at n = 5, mu = lambda AND M = nu.
     10,813 exact 5-player games, ZERO violations, of which 9,614 come from
     COMPLETE enumerations:
        complete 2-generator, totals 2..24 ............ 4,357   100%
        complete 3-generator, T = 4 / 5 / 6 ........... 335 / 1,175 / 3,747  100%
        random envelopes, k = 2..7 .................... 1,199   100%
     PROVABLY an n=5 fact: the M-side is FALSE from n = 6 (P12), with tightness
     rates 100 / 100 / 97 / 89 % at n = 4 / 5 / 6 / 7.  This is the cleanest
     formal expression of the n=5 versus n>=6 regime change.
V2.  At n = 5 the nu-tight family never covers N when nu > T/n: 0 out of 735
     applicable games.  At n = 6 it does, in 5 of 878.  (Covering is sufficient
     for M > nu by P11 but not necessary: n = 6 had 12 games with M > nu.)
V3.  s(5) = 1/2.  Complete 2-gen (4,357) and 3-gen (15,180) enumerations; seeded
     core-polytope climbing over ALL exact games (240 steps, no improvement);
     fine-denominator shape climbing at resolution 1/60 (no improvement);
     controls at n = 3, 4 returning 0.  Nothing above 1/2 in ~42,000 games.
V4.  Configuration CFG forces rho = 1/2 exactly: 53 of 53.
V5.  rho > 0 implies Lmin has a slack boundary: 0 counterexamples in 699 games.
V6.  s_2(n) = 2 - 8n/(n^2 - (n mod 2)) for the two-generator class: confirmed by
     COMPLETE enumeration at n = 6 (8,213 games), n = 7 (1,609), n = 8 (1,049),
     and by shape scans at n = 9, 10.
V7.  Two-generator extremality: from the known optimum at n = 5,6,7,8, ~200
     structured plus random third generators each gave ZERO improvements; and
     SEEDED c-space climbing (which searches all exact games) found no
     improvement at n = 5 (240 steps), n = 6 (496), n = 7 (301).  So the
     two-generator optimum is a certified LOCAL optimum in the full exact class
     at n = 5,6,7.
V8.  n = 5 extremal rigidity: all 107 distinct rho = 1/2 games share ONE
     (Lmin, Lmax) pair up to permutation and scaling, namely
     (1/2,1/2,1/2,5/4,5/4) and (0,1,1,1,1) at T = 4, with Lmin strata (3,2),
     Lmax strata (1,4), exactly one zero, |supp(Lmax)| = 4.

4.  OPEN, each with its sharpest known obstruction
================================================================================
O1.  A3 (mu = lambda and M = nu at n = 5).
     REDUCED (P9, P10, P11) to: no family of nu-tight (resp. lambda-tight)
     coalitions on 5 players that arises from an exact game can cover N while
     containing no balanced subcollection.  Such families DO exist at n = 6
     (P12).  The remaining work is a finite question about 5-player covering
     structures compatible with the exact cone -- plausibly decidable against
     the companion programme's facet catalogue, which is why I flag it as the
     most attackable item on this list.
O2.  (*)  f({j}) >= T/8, where j is the player Lmax starves.  Equivalently
     v(N\{j}) <= 7T/8; equivalently "the starved player can still collect an
     eighth of v(N) somewhere in the core".  Verified 95/95.  This is the ONLY
     gap in the CFG case of s(5) = 1/2.  It is the same one-coalition-versus-
     fractional-cover phenomenon as O1, and would very likely fall out of O1.
O3.  s(5) = 1/2 in full.  Even with O2, three configurations are untreated:
     the other Lmax stratum shapes ((1,2,2) 55 games, (1,1,3) 3 games, none
     ever reaching 1/2); the (4,1) Lmin boundary (never exceeds 1/3 -- proving
     it would give the two-regime theorem (4,1) <= 1/3 < (3,2) <= 1/2); and the
     sub-case where the starved player is Lmin-RICH, which occurs 0/68 times but
     is not excluded by my argument.
O4.  s_2(n) = 2 - 8n/(n^2 - (n mod 2)) as an upper bound.  Any true bound must
     be asymptotically 2, so every "c*v(N) with c < 2" target is false for large
     n.  ONE ROUTE IS CLOSED: the natural "uniform-h is WLOG by majorization"
     strategy FAILS -- a Robin-Hood transfer inside the h-block decreases the
     ratio in 13-45% of steps at every block size including |B| >= 4, with a
     verified |B| = 4 counterexample (n = 7, T = 10, g = (0,5,0,3,2,0,0),
     h = (1,0,2,0,0,5,2), rho = 1/5, and smoothing (5,2) -> (4,3) collapses
     Lmin = Lmax to rho = 0).  rho is NOT monotone under majorization of h, so
     any proof must handle general h directly.
O5.  Extremality of the two-generator class.  Adding a generator LOWERS the
     envelope and hence GROWS the core, so this is not automatic; V7 is
     suggestive only.
O6.  A structural account of the n = 5 versus n >= 6 regime change.  V1/P12 now
     give it a precise formal shape (one-coalition certificates exist at five
     players, fail at six); what is missing is the reason five is the threshold.

================================================================================
5.  RETRACTED / CORRECTED DURING THE CAMPAIGN  (kept deliberately)
================================================================================
R1.  (n-4)/(n-3) as the answer -- refuted at n = 7 (max 5/6 > 3/4).  My error
     was fitting a formula to a family extracted from the n=5 and n=6 witnesses
     and then scanning only that family; the block shape was wrong.  COMPLETE
     enumerations are authoritative, family scans are not.
R2.  The target lemma ||Lmin - Lmax||_1 <= 4(n-4)*min_i Lmin_i -- true and tight
     for n <= 8 (both sides equal 12 at G(3,4)), FALSE from n = 9 (G(4,4): 88/5
     versus 16).  Structural reason: it is linear in mu = p/(p+1), which stays
     bounded, while the gap grows like 2T.
R3.  The (n-2)/6 fit -- matched n = 5,6,7,8 and died at n = 9 (11/10, not 7/6).
R4.  "Lmax stratum shape (1,4) implies the small stratum vanishes" -- FALSE.
     Games with Lmin (3,2), Lmax (1,4) and min Lmax > 0 take ratios 2/9, 1/12,
     8/21, 4/13, ...  The zero is a genuinely extra hypothesis; CFG must be
     stated with it.
R5.  "|B| = 4 is special" -- no.  k = |B| is free and the optimum is k ~ n/2;
     the earlier 3/2 limit was an artifact of fixing k = 4, beaten from n = 10.
     In G(p,k) every Lmax coordinate is positive, so |supp(Lmax)| = n and NO
     player is starved; the |supp(Lmax)| = 4 invariant is an n = 5 phenomenon.
R6.  A verification count was mis-stated as 488/488; the correct total is 586
     (120 + 218 + 165 + 83 at n = 4,5,6,7).  Rates unchanged.
R7.  "Smoothing h toward uniform helps" -- false (O4).

6.  METHOD NOTES worth carrying forward
================================================================================
M1.  Complete enumeration up to total T covers exactly the rational shapes with
     denominator <= T, since the ratio depends only on the shape.  It is a
     lower-bound method, never a supremum determination.  Fine-denominator
     climbs (resolution 1/60) were run to guard this at n = 5,6,7.
M2.  For ANY vector c over proper coalitions, P(c) = {x : x(N)=T, x(S) >= c_S},
     when nonempty, is exactly the core of the exact game v(S) = min_{P(c)} x(S),
     and core(v) = P(c).  So "core-closing" an arbitrary c always lands in the
     exact class: this gives a search over ALL exact games, reaching cores with
     arbitrarily many vertices.  UNSEEDED restarts are far too weak at n >= 6
     (they reach only 1/3 where the truth is 2/3); only SEEDED runs certify.
M3.  sympy.solvers.simplex cycles on these degenerate LPs (InfeasibleLPError).
     Every number here was produced with exact Fractions and cross-checked
     between staged z3 LRA and a from-scratch Bland-rule simplex.
M4.  Retract your own conjectures loudly and with the structural reason; R2 in
     particular would have cost someone a wasted proof attempt.
