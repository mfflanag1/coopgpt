STATEMENT
--------------------------------------------------------------------------------
THEOREM (thm:cfg).  Let v be a singleton-normalized exact five-player game in
configuration CFG: writing x = Lmin(v), z = Lmax(v), T = v(N),
  * the Lmin strata are (3,2): a bottom stratum P of three players at level mu
    and a top pair R = {r1,r2} at level rho, so 3mu + 2rho = T;
  * the Lmax strata are (1,4) with the singleton at zero, at player j.
Then f({j}) := T - v(N\{j}) >= T/8.

CONVENTIONS.  T = 1 by homogeneity.  f(S) = 1 - v(N\S);
lambda = min_{S nonempty} f(S)/|S|.  Core duality (paper5 Lemma A1, all games):
Core(v) = {y >= 0 : y(N) = 1, y(S) <= f(S) for all S}.  Call S *f-tight* when
x(S) = f(S); equivalently N\S is v-tight at x.

INPUTS, all established and all cheap:
 (A2)  mu <= lambda.  [paper5 Lemma A2 / route1 A2; true for ALL games:
       x is a core point, so |S| mu <= x(S) <= f(S) for every S.]
 (PS)  j lies in P.   [paper5 cor:poorstarved / s5close L2', a two-line hand
       result.]
 (X)   x and z are core points.  [by construction]
 (PIN) the Lmin bottom stratum is pinned: max{y(P) : y in Core(v),
       y >= mu*1} = 3mu.  [the meaning of "P is the Lmin bottom stratum"]

NOTE WHAT IS *NOT* USED: the hard direction of A3 (mu = lambda), the M-side
(nu = M), the Studeny-Kratochvil facet description, and any enumeration.  The
ablation in verifiers/o2/ancillary had already found the minimal sufficient
hypothesis set to be {z in Core} + {x in Core} + {pinning} + failure; this
proof realizes exactly that set, and drops A3 as well.

--------------------------------------------------------------------------------
PROOF
--------------------------------------------------------------------------------
Suppose, for contradiction, f({j}) < 1/8.

STEP 0 (the failure hypothesis reaches mu).  lambda <= f({j})/1 < 1/8, so by
(A2) mu < 1/8.  Hence rho = (1 - 3mu)/2 > 5/16 > 1/4.  Note also
mu < 1/8 < 1/5 gives c := 1 - 5mu > 0.  Write P = {j, p1, p2}.

STEP 1 (THE KEY LEMMA).  Every f-tight S satisfies
        |S n {p1,p2}|  <=  |S n R| .
PROOF.  Put U = N\S, so U is v-tight: x(U) = v(U).  Since z is a core point,
v(U) <= z(U).  Writing a = |U n P|, b = |U n R|, eps = [j in U] (so a >= eps),
and using x = mu on P, rho on R, and z = 0 at j and 1/4 elsewhere,
        mu*a + rho*b  =  x(U) = v(U) <= z(U) = (a + b - eps)/4 .     (KEY)
The claim is b <= a - eps.  As |U n {p1,p2}| = a - eps <= 2 and b <= 2, a
violation b >= a - eps + 1 leaves only these cases, each killed by (KEY):
  a-eps = 0, eps = 0 (so a = 0, U in R), b >= 1:
        rho*b <= b/4  gives rho <= 1/4, against rho > 1/4.
  a-eps = 0, eps = 1 (so a = 1, U n P = {j}), b >= 1:
        mu + rho*b <= b/4  gives mu <= b(1/4 - rho) < 0, against mu >= 0.
  a-eps = 1, eps = 0 (a = 1, U = {p_i} u R), b = 2:
        mu + 2rho <= 3/4, and 2rho = 1 - 3mu, so 1 - 2mu <= 3/4,
        i.e. mu >= 1/8 -- against mu < 1/8.                          (*)
  a-eps = 1, eps = 1 (a = 2, U = {j,p_i} u R), b = 2:
        2mu + 2rho <= 3/4, i.e. 1 - mu <= 3/4, i.e. mu >= 1/4.
Finally |S n {p1,p2}| = 2 - (a - eps) and |S n R| = 2 - b, so b <= a - eps is
the claim.                                                                  []

STEP 2 (the pinning, dualized).  Substituting u = y - mu*1 turns (PIN) into
        max { u(P) : u >= 0, u(N) = c, u(S) <= h(S) for proper nonempty S } = 0,
where h(S) := f(S) - mu|S| >= 0 by (A2).  By LP duality there are alpha and
beta >= 0 with
        alpha + B_k >= [k in P]  for every player k,   B_k := sum_{S ni k} beta_S,
        alpha*c + sum_S beta_S h(S) <= 0 .
Since c > 0 and h >= 0, the second line forces alpha <= 0; put A := -alpha >= 0.
The first line reads
        B_k >= 1 + A  (k in P),        B_k >= A  (k in R).                (L)

STEP 3 (the x-bound is exactly tight, and that is the whole content).  x is a
core point, so h(S) >= x(S) - mu|S| = (rho - mu)|S n R|.  Hence
        sum_S beta_S h(S)  >=  (rho - mu)(B_{r1} + B_{r2})
                           >=  (rho - mu)*2A  =  (1 - 5mu)A  =  cA,
using 2(rho - mu) = (1 - 3mu) - 2mu = 1 - 5mu.  But Step 2 gives
sum_S beta_S h(S) <= cA.  So BOTH inequalities are equalities, and therefore
   (i)  B_{r1} + B_{r2} = 2A;
   (ii) h(S) = x(S) - mu|S| for every S in supp(beta), i.e. every support set
        is f-TIGHT.

STEP 4 (counting).  By (ii) the key lemma applies to every support set, so
        B_{p1} + B_{p2} = sum_S beta_S |S n {p1,p2}|
                       <= sum_S beta_S |S n R| = B_{r1} + B_{r2} = 2A,
while (L) gives B_{p1} + B_{p2} >= 2(1 + A) = 2 + 2A.  Hence 2 + 2A <= 2A, a
contradiction.  Therefore f({j}) >= 1/8.                                    []

--------------------------------------------------------------------------------
WHERE THE CONSTANT COMES FROM, AND WHY IT IS SHARP
--------------------------------------------------------------------------------
Exactly one line of the proof mentions 1/8: the case marked (*), where the
v-tight set U = {p_i} u R gives 1 - 2mu <= 3/4.  Every other case is killed
with room to spare (rho > 1/4, mu >= 0, mu >= 1/4).  So the theorem's constant
is the threshold of that single inequality, and the proof cannot be pushed
past it.

At mu = 1/8 the case (*) becomes an equality and the key lemma fails, at the
f-tight set S = N\U = {j, p_other}, for which |S n {p1,p2}| = 1 > 0 = |S n R|.
That is not hypothetical.  In paper5's own extremal game (Theorem thm:n5, the
lower envelope of (1,0,0,1,2) and (0,1,3,0,0), T = 4, ratio 1/2) one has
Lmin = (1/2, 1/2, 5/4, 1/2, 5/4), Lmax = (1,0,1,1,1), so CFG holds with
mu = 1/2 = T/8, rho = 5/4 = 5T/16, j = b; and the f-tight sets ab and bd are
precisely {j,p1} and {j,p2}, both violating the key lemma, both with
complement shape (a,b,eps) = (1,2,0).  Machine-confirmed in reality2.py.

The same computation reproduces the mechanism the paper's own
Corollary cor:cfg exhibits from the other side: there a three-player coalition
S0 attaining nu gives f(N\S0) = 1/4 on two players, and N\S0 = {j,k} is exactly
this set.

--------------------------------------------------------------------------------
WHAT THE PROOF SAYS, IN WORDS
--------------------------------------------------------------------------------
The pinning of the poor stratum must be paid for.  Step 3 shows the only
currency available is the two rich players: the cheapest possible certificate
already costs exactly the whole budget cA, so the certificate must be exactly
optimal -- every coalition it uses is a cap of Lmin, and the rich loads are
exactly A.  Step 1 then says that a cap of Lmin can never touch the two
non-starved poor players more often than it touches the rich pair.  So the
certificate cannot deliver the load 1 + A that each of p1 and p2 requires: it
can supply at most what the rich pair supplies, which is A each on average.
The starved player j is irrelevant to the count -- the free coalition {j} that
the failure hypothesis creates is exactly the one the key lemma exempts -- and
that is why the argument sees the failure hypothesis only through mu < 1/8.
