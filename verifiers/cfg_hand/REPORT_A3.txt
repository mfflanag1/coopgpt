TARGET 1 -- CFG's f({j}) >= T/8 BY HAND.  CRACKED.
--------------------------------------------------------------------------------
Full proof in PROOF_A3.txt; verified by verify_hand_cfg.py and reality2.py.
Reported and archived by the lead at verifiers/cfg_hand/.  One page, no vertex
enumeration, no 354 pinning-dual vertices, no catalogue, and it does not use
A3's hard direction -- only A2 (mu <= lambda, true for all games).

Summary of the mechanism: dualizing the pinning gives a certificate of cost at
most cA; core membership of Lmin forces its cost to be at least cA, because
2(rho - mu) = 1 - 5mu EXACTLY; so the certificate is squeezed to exact
optimality, hence every coalition it uses is a cap of Lmin; and a cap of Lmin
can never touch the two non-starved poor players more often than the rich pair
(the key lemma, from core membership of Lmax).  The load count then fails by
exactly 2.  The constant 1/8 appears in one line only and is sharp: at
mu = T/8 the key lemma fails at the single shape (a,b,eps) = (1,2,0), realized
in paper5's own extremal game.

TARGET 2 -- mu = lambda AT n = 5 BY HAND.  PARTIAL.
--------------------------------------------------------------------------------
Not proved.  What is delivered is a reduction that turns the theorem into a
finite, explicitly enumerated question, plus two lemmas that remove 91% of it.
The residue is 210 objects with support 2 or 3, described exactly below.

THE REDUCTION (proved).  mu = max{t : exists y in Core, y >= t*1}.  Put
u = y - t*1 and g_t(S) = f(S) - t|S|.  Nonnegativity of u forces g_t >= 0, i.e.
t <= lambda -- which is A2, recovered.  At t = lambda, writing g := g_lambda >= 0
and g(N) := T - n*lambda,

      mu = lambda   <=>   max{ u(N) : u >= 0, u(S) <= g(S), S proper } >= g(N),

and by LP duality the max is a min over FRACTIONAL COVERS -- beta >= 0 on
proper coalitions with load c_k := sum_{S ni k} beta_S >= 1 for every k.  Hence

      mu = lambda   <=>   sum_S beta_S g(S)  >=  g(N)
                          for every vertex beta of the cover polyhedron.   (C)

This is the precise form of the "one coalition versus a fractional cover"
obstruction that records/S5PROOF.txt Part D named and could not pin down: the
floor level is certified by ONE cap exactly when no fractional cover of the
player set undercuts g(N).

LEMMA B (balanced covers are free; any n, any game with a nonempty core).
If c_k = 1 for every k then for any core point y,
      sum_S beta_S g(S) >= sum_k c_k (y_k - lambda) = sum_k (y_k - lambda) = g(N),
using f(S) >= y(S).  So a balanced cover can never witness failure.
PROOF NOTE: the first step is f(S) >= y(S) summed with weights beta; the second
is c_k = 1.

LEMMA E1 (single excess player).  Let E := {k : c_k > 1}.  The general bound
reads sum_S beta_S g(S) >= sum_k c_k(y_k - lambda), so (C) holds as soon as
some core point y has y_k >= lambda for every k in E, since then
sum_k (c_k - 1)(y_k - lambda) >= 0 termwise.  If |E| = 1, say E = {k}, such a y
exists: lambda <= f({k}) and exactness at {k} supplies a core point attaining
f({k}).  So every vertex with |E| = 1 is free.

LEMMA C (equal excess).  If the excess weights w_k = c_k - 1 are CONSTANT on E,
the requirement is y(E) >= lambda|E| for some core point, and
max_y y(E) = f(E) >= lambda|E| by the definition of lambda.  Free.
  COROLLARY (all support-2 vertices are free).  A support-2 vertex has
  S1 u S2 = N with A = S1\S2, B = S2\S1 nonempty, beta = (1,1), and
  E = S1 n S2 carrying c = 2 throughout.  Directly: the cover inequality reads
  v(A) + v(B) <= T - lambda|C|, and v(A)+v(B) <= T - max_y y(C) = T - f(C)
  <= T - lambda|C|.

WHAT SURVIVES (covers.py, covers2.py, covers3.py; exact rational enumeration):
      cover vertices at n = 5                        2286
        balanced, killed by Lemma B                  1291
        |E| = 1, killed by Lemma E1                   785
        equal excess, killed by Lemma C               150
        REMAINING                                      60
      and the 60 are ONE SHAPE up to relabelling (machine-confirmed):
        S1 = {p,x},  S2 = {p,q,y},  S3 = {p,q,z},  beta = (1,1,1),
        loads p:3, q:2, x,y,z:1, so E = {p,q} with excess weights (2,1).
      60 = 5*4*3, the number of labellings.

So the whole of mu = lambda at n = 5 reduces to ONE inequality:

      (R)     max_{y in Core} ( 2 y_p + y_q )  >=  3*lambda

for every ordered pair p != q.  Equivalently
f({p,x}) + f({p,q,y}) + f({p,q,z}) >= T + 3*lambda, equivalently
v({q,y,z}) + v({x,z}) + v({x,y}) <= 2T - 3*lambda.

LEMMA D (half of (R), free).  Dualizing max sum_k w_k y_k over
Core = {y >= 0, y(N) = T, y(S) <= f(S)} gives
      min { eta*T + sum_S gamma_S f(S) : gamma >= 0, eta + Gamma_k >= w_k },
with Gamma_k = sum_{S ni k} gamma_S.  If eta >= 0 then, using f(S) >= lambda|S|,
      eta*T + sum_S gamma_S f(S) >= eta*T + lambda*sum_k Gamma_k
                                 >= eta*T + lambda*sum_k (w_k - eta)
                                 =  3*lambda + eta*(T - 5*lambda)  >=  3*lambda,
because T >= 5*lambda.  So (R) CAN ONLY FAIL THROUGH A DUAL OPTIMUM WITH
eta < 0.  That is the failure boundary, and it is where I stopped.

(R) IS SHARP, NOT SLACK.  Over 250 random genuine exact five-player games and
all 20 ordered pairs (p,q) each, the margin max(2y_p+y_q) - 3*lambda is
nonnegative always and EQUALS ZERO somewhere.  So (R) is a real constraint that
the games meet exactly -- which is why it is the one surviving all four free
lemmas, and why no cruder bound will dispose of it.

WHERE FIVE-NESS WOULD ENTER, on this evidence.  Lemmas B, C, E1 and D are all
dimension-free.  Five-ness can only be in the residue, and the residue is now a
single named shape whose complement structure -- one 3-set and two 2-sets -- is
specific to n = 5: at larger n the same vertex family has more members and more
shapes.  A hand proof of (R), or a demonstration that its eta < 0 branch is
empty at n = 5 but not at n = 6, IS the "why five" answer.

CROSS-CHECK ON AN ARCHIVED COUNT.  verifiers/a3check/coververt.py is recorded
in the verifiers README as producing 2287 cover vertices; my enumeration gives
2286.  These agree: a3check takes SETS = range(1, FULL+1), which INCLUDES the
grand coalition, while the duality above ranges over PROPER coalitions only
(the grand coalition's constraint is the efficiency equality, not a cap).  The
one extra vertex is the trivial cover beta_N = 1.  Flagged so the two numbers
are not later read as a discrepancy.

TARGET 2, ROUND 4: TWO LEADS RESOLVED (one negatively, one decisively)
--------------------------------------------------------------------------------
THE R4 / MERGE ROUTE IS THE WRONG DIRECTION.  REFUTED.
The suggestion was to contract a surviving vertex's sub-problem to a game on
<= 4 players and kill it with R4, using the merge lemma (PART round, M1:
contracting a coalition of an exact game preserves exactness).  It cannot work,
for a structural reason that needs no computation: pi(y) = (y_p, y_q,
y(B) - v(B)) maps Core(v) INTO Core(w'), and the objective 2y_p + y_q is
unchanged by pi, so
        max over Core(w')  >=  max over Core(v).
(R) needs a LOWER bound on the right-hand side; the merge supplies an upper
bound on it.  The route survives only if pi is ONTO.  It is not:
merge_route.py, over 120 random exact five-player games, finds the two maxima
equal in 117 and STRICTLY LARGER on the merged game in 3, by as much as 2.
So the contraction genuinely loses core points, and the floor bound does not
transport even though exactness does.  (The lead's hope was that transporting
the FLOOR rather than the full selection would dodge M1's known limitation; it
does not -- the obstruction is the direction of the inequality, not which
object is transported.)

EXACTNESS IS LOAD-BEARING.  CONFIRMED BY COUNTEREXAMPLE.
The residual inequality is v({q,y,z}) + v({x,z}) + v({x,y}) <= 2T - 3*lambda.
BALANCEDNESS alone cannot reach it: the collection above together with
2*{p} + {q} is balanced with r = 2, and singleton values vanish, so
balancedness yields only <= 2T; replacing 2*{p}+{q} by {p,q}+{p} yields
<= 2T - v({p,q}), and v({p,q}) can be 0.  Either way one is short by 3*lambda.
So any proof must use exactness.  That is not a guess: exactness_needed.py
exhibits a BALANCED (nonempty core) but NON-EXACT five-player game with
        T = 8,   mu = 8/5  <  5/3 = lambda,   gap 1/15,
        v = {ab:2, ac:3, bc:2, abc:1, ad:2, bd:3, cd:1, acd:4, bcd:3, be:3,
             abe:3, ace:4, bce:3, abce:2, ade:1, abde:4, cde:2, acde:5, bcde:1}.
So mu = lambda is FALSE for balanced games at n = 5, and every free lemma above
(B, C, E1, D) is consistent with that -- each uses only core membership, which
balanced games have.  The exactness content must therefore enter precisely at
the residual shape, and nowhere else.

WHAT THIS LEAVES.  The residue is one inequality (R), it is sharp, it fails only
through eta < 0, it cannot be obtained from balancedness, and it cannot be
reduced to <= 4 players by contraction.  Those four facts together are a tight
specification of what a proof must look like: an argument that consumes
exactness at a five-player configuration, in the eta < 0 branch of one dual, and
does not factor through any contraction.  That is the sharp form of paper5's
"why five" and is, in my judgement, the right way to state the open problem in
print.

TARGET 2, ROUND 5: THE CHAIN-ATTAINMENT REFORMULATION IS FALSE; THE eta<0
BRANCH IS ACTIVE
--------------------------------------------------------------------------------
CHAIN ATTAINMENT: REFUTED at n = 5.  The proposed sufficient statement was that
a nested pair of f-caps is simultaneously attainable -- some core point with
y_p = f({p}) AND y_p + y_q = f({p,q}), which would give (R) at once since
f({p}) + f({p,q}) >= 3*lambda.  Tested exactly (chain.py) on 200 genuine exact
five-player games and all 4000 ordered pairs: attainable on 3936, NOT
attainable on 64.  Explicit failure: T = 14, p, q with f({p}) = 4 and
f({p,q}) = 12, but max over the core of 2y_p + y_q = 15 < 16 = f({p}) + f({p,q}).
So the two caps cannot be saturated together.
IMPORTANTLY (R) SURVIVES: on all 64 failures the margin
max(2y_p+y_q) - 3*lambda is >= 0, minimum 1.  Chain attainment is strictly
stronger than (R), and it is the strictly stronger statement that is false.

THE eta < 0 BRANCH IS ACTIVE, SO LEMMA D DOES NOT CLOSE (R).  If the dual
optimum were always attained at some eta >= 0, Lemma D would certify (R) and
mu = lambda would be a hand theorem.  Tested (eta.py) by solving the dual twice,
once unrestricted and once with eta >= 0 imposed, on 60 games and 1200 ordered
pairs: the optimum is unchanged on 1187 and STRICTLY WORSE under eta >= 0 on 13.
So the eta < 0 region genuinely carries content -- rarely (about 1%), but it
cannot be discarded.  In all 13 the free optimum is still >= 3*lambda, as it
must be.

AND THE FALLBACK IS NOT A REDUCTION.  By LP strong duality the dual optimum
EQUALS max over the core of (2y_p + y_q).  So "characterize the eta < 0 dual
vertices and kill them against exactness" is not logically easier than (R) --
it is (R), restated on the other side.  That does not make it a bad tactic: the
dual vertices are finitely many shapes and enumeration is exactly what worked
on the primal side.  But it should be pursued as an enumeration strategy, not
as a simplification, and any claim that it "reduces" (R) would be wrong.

NET EFFECT ON THE SPECIFICATION.  A proof of (R) must, in addition to the four
constraints of round 4, engage a dual region that is active on roughly 1% of
instances and cannot be reached by saturating the two caps of the chain
simultaneously.  That is a fifth constraint, and the rarity is itself a hint:
whatever exactness supplies is needed only on a thin set of games.

CORRECTION (2026-08-09, lead-caught).  THE LAMBDA CONVENTION.
================================================================================
WHAT WAS WRONG.  All four empirical scripts of rounds 3-5 (covers3.py, chain.py,
eta.py, exactness_needed.py) computed lambda as a minimum over PROPER coalitions
only.  paper5's lambda ranges over ALL nonempty S INCLUDING N, so the correct
value is lambda = min(lambda_proper, T/5).  A systematic convention slip, in
four places, mine.

WHAT IT COSTS: CONSTRAINT (ii) IS WITHDRAWN.  My round-4 "balanced game with
mu < lambda" had T = 8, lambda_proper = 5/3, mu = 8/5.  But T/5 = 8/5, so the
true lambda is 8/5 = mu: the game satisfies mu = lambda and refutes nothing.
It is also OUT OF REGIME (lambda_proper = 5/3 > 8/5 = T/5).  Verified.
So "exactness is load-bearing" is NOT established.  What survives is only the
SYNTACTIC observation that balanced-collection bookkeeping cannot derive the
residual inequality (short by 3*lambda) -- a statement about one proof template,
not about games.

WHAT IT ADDS: THE FREE ZEROTH FILTER (the lead's, and it is a real lemma).
If lambda_proper > T/5 then lambda = T/5, so g(N) = T - 5*lambda = 0 while
g >= 0 on every proper S; the cover inequality sum beta_S g(S) >= g(N) = 0 is
then automatic.  Hence mu = lambda holds for ANY game with a nonempty core
outside the regime lambda_proper <= T/5.  Machine-checked: of 400 random exact
games, 127 were out of regime and every one had mu = lambda.  This belongs at
the FRONT of the decomposition, before Lemmas B/C/E1/D: the entire open problem
lives in the regime lambda_proper <= T/5.

WHAT SURVIVES UNCHANGED.  The structural derivation never used lambda_proper:
the reduction needs g >= 0 on proper S (i.e. lambda <= lambda_proper) and
g(N) = T - 5*lambda >= 0 (i.e. lambda <= T/5), and Lemma D explicitly uses
T >= 5*lambda -- which is exactly the N-inclusion the slip dropped.  So
Lemmas B, C, E1, D, the 2286 -> 60 -> one-shape localization, and the merge
refutation are all unaffected.  Re-run with the correct lambda IN REGIME, (R)
is STILL TIGHT: smallest margin 0, at T = 7.  The empirical claims of rounds 3
and 5 were tested against lambda_proper >= lambda, i.e. a HARDER condition, so
their "margin >= 0 always" conclusions hold a fortiori.

AND IT OPENS A NEW QUESTION, which may matter more than what it closed.
Hunting for a genuine in-regime witness -- balanced, non-exact,
lambda_proper <= T/5, mu < lambda -- found NONE in 20,000 sampled balanced
games.  If none exists, core membership alone proves (R) and exactness is NOT
where the content of mu = lambda lives, which would reopen the localization of
round 4 entirely.  I could not settle this: my sampler draws v coordinatewise
at random and is poor at producing interesting balanced non-exact games, so
absence here is weak evidence.  Recorded as OPEN, not as evidence either way.

REVISED CONSTRAINT LIST for a proof of (R): (i) establish (R); (iii) engage the
eta < 0 dual region, active on ~1% of instances; (iv) not factor through
contraction; (v) not proceed by chain saturation.  Constraint (ii) is struck
pending an in-regime witness.
