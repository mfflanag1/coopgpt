1.  WHAT WAS ADDED:  SEVEN LEMMAS, ONE IDEA
--------------------------------------------------------------------------------
Every new lemma is the same observation applied once -- both selections optimize
a staged program over the core, so a core direction that improves the objective
must leave the polytope.  All are A3-free and none needs a solver.  Statements
and proofs: PROOF27.txt.

  L7    every core point w has max_{i in D1} w_i >= M
  L7'   every core point w has min_{i in P}  w_i <= mu
  L5    min Lmax <= min Lmin and max Lmax <= max Lmin
  L1''  the Lmax top stratum has >= 2 players            (A3-FREE)
  L6    if the Lmin bottom stratum is a singleton {i} then f({i}) = mu
  L11   x_i < x_j => some proper A with j in A, i not in A has x(A) <= z(A)
  L12   z_i < z_j => some proper A with j in A, i not in A has z(A) <= x(A)

TWO OF THESE CHANGE THE STATUS OF EARLIER RESULTS.
 * L7' with w = z IS L2(c).  So L2, and its corollary L2' (the Lmax-starved
   player is Lmin-poor -- the one that replaced 10,974 programs), are A3-FREE.
 * L1'' replaces L1', so the 1953 exclusions no longer route through A3.
Between them, the A3-dependence of the STRUCTURAL story is now confined to the
anchor conditions, which buy only 204 -> 132.

L11/L12 are the productive pair: they are the first lemmas that constrain the
two allocations AGAINST EACH OTHER on a specific coalition, and they are what
takes 377 -> 204 and 208 -> 132.

5.  INCREMENT 2:  TIGHT-FAMILY LEMMAS (TRUE, AND THEY BUY NOTHING), AND THE
    NAMED RESIDUE
--------------------------------------------------------------------------------
FOUR MORE LEMMAS, ALL VERIFIED, ALL A3-FREE (tightfam.py -> tightfam.json).
The protectors supply tight coalitions one at a time; these say how tight
coalitions combine.  phi is a core point, "phi-tight" means phi(A) = v(A).
  L14  A, B disjoint and phi-tight  =>  A u B is phi-tight
       (superadditivity one way, core membership the other).
  L15  A x-tight, B z-tight, A subset B  =>  x(A) <= z(B)   (monotonicity).
  L16  A x-tight, B z-tight, disjoint  =>  x(A)+z(B) <= min(x(AuB), z(AuB)).
  L17  A both x- and z-tight  =>  x(A) = z(A).
Verified on all 2668 harvested games: L14 16,286 cases, L15 42,455, L16 16,917,
L17 15,194 -- 0 failures each; monotonicity and superadditivity of v, on which
they rest, also 0 failures.
CHECKED AND FALSE, SO NOT USED: the tight family is NOT closed under
complementation (the complement of a tight set failed to be tight in 4,433 of
15,335 cases).  A x-tight gives only v(N\A) <= x(N\A), which is core
membership again.

NEGATIVE RESULT, REPORTED AS SUCH.  Adding all four to the net (arith27c.py,
net HAPT: Boolean tight-markers per coalition, with the protectors supplying
them and L14-L16 propagating) kills EXACTLY ZERO further configurations:
132 in, 132 out.  So the tight-family closure, though true and not obvious, has
no consequences for the LEVELS beyond what L11/L12 already extract.  Soundness
of the stronger net was checked too: of the 21 configurations the harvests
actually produce, 0 are wrongly killed.

THE RESIDUE, NAMED (target (c) of the assignment).  Splitting the 132 by
whether the configuration can occur at all (the A3-free encoding's positive
control):

   27  POSSIBLE configurations.  These can NEVER be killed by any level-only
       net, because they exist.  For each, excluding ratio > 1/2 is exactly a
       LOWER BOUND ON mu -- inequality (*) of records/S5PROOF.txt Part D.
       They include CFG, (3,2)x(1,2,2), (4,1)x(1,4) and (4,1)x(2,3), i.e. the
       four two-stratum cases of section 3, plus 23 with three or more Lmin
       strata.  This is the irreducible core of the whole problem.
  105  IMPOSSIBLE configurations not yet hand-excluded.  Reachable in
       principle.  They concentrate sharply in Lmin shapes with many strata:
       (1,1,1,1,1) 22, (2,1,1,1) 21, (1,1,2,1) 12, (1,2,1,1) 11, (2,2,1) 11,
       (3,1,1) 10 -- 87 of the 105 have three or more Lmin strata.

WHY THAT CONCENTRATION, AND WHERE THE NEXT LEMMA MUST COME FROM.  L7 and L7'
are statements about the EXTREME strata only -- the Lmax top and the Lmin
bottom.  A configuration with many strata has middle strata about which the
whole net says nothing beyond the protectors.  The natural fix is the stage-2
extremal rigidity, and the same perturbation proves it:

  L13.  Every core point w with w <= M*1 satisfies max_{i in D2} w_i >= M2,
        where D2 is the second Lmax stratum and M2 its level.
        (The stage-1 feasible set IS {w in Core : w <= M*1}, since pinning is
        what forces w = M on D1 there; then perturb inside it exactly as in L7.)

L13 is true and proved, but it is NOT usable in a level-only net as things
stand: to extract a consequence one must instantiate w at a known point of
{w in Core : w <= M*1}, and the only canonical such point is z itself, which
makes the statement vacuous.  L7 was usable precisely because x is a core point
available for free.  So the barrier at 132 is not a shortage of true lemmas --
it is the absence of a second canonical core point inside the stage-1 face.
Manufacturing one (for instance the leximin point OF THE FACE, or the core
point attaining v(S) for a well-chosen S via Theorem A) is the concrete next
step, and it is what I would attack first.

7.  INCREMENT 3:  THE MIDDLE-STRATUM ROUTE IS CLOSED OFF (NEGATIVE, DECISIVE)
--------------------------------------------------------------------------------
Increment 2 diagnosed the barrier as "L7/L7' speak only about the extreme
strata".  Rather than guess a middle-stratum lemma, increment 3 SCREENS eight
candidates against all 2668 harvested genuine exact games (cands.py ->
cands.json, which stores a counterexample game for each casualty).

  C1  L7 generalized: for EVERY Lmax stratum l, some i in D^l has x_i >= M_l
                                                          DEAD, 233 failures
  C2  L7' generalized to every Lmin stratum               DEAD, 144
  C3  z(D1) <= x(D1)   (top-stratum sum domination)       DEAD, 403
  C4  x(P)  >= z(P)    (bottom-stratum sum domination)    DEAD, 453
  C5  z(U) <= x(U) for every Lmax rich suffix U           DEAD, 617
  C6  x(L) >= z(L) for every Lmin poor prefix L           DEAD, 621
  C7  Lmin LORENZ-DOMINATES Lmax                          DEAD, 1102
  C8  the face instantiation (applies exactly when max x = M)  survives, 4923

C7 IS WORTH RECORDING ON ITS OWN.  The leximin point of an exact game's core is
NOT Lorenz-greatest in general -- 1102 violations.  That kills an entire family
of would-be arguments (anything that tries to compare partial sums of the two
selections) and shows that the exact-partition hypothesis in Lemma 0 of
s5full/REPORT.txt is doing real work rather than being a convenience.

C8 is the only survivor and it is conditional: by L5, M <= max x always, so the
hypothesis max x <= M means max x = M exactly, and then x lies in the stage-1
face {w in Core : w <= M*1} and L13 applies at w = x.  Useful where it applies,
but it is not the unconditional middle-stratum lemma the net needs.

THE SECOND-CANONICAL-POINT ROUTE, TESTED.  Instantiating L7/L7' at the
Theorem-A attaining points w^S yields, for S containing D1, only v(S) >= M --
which the net already implies.  Other choices of S bound only one coordinate of
w^S and give nothing at the level of stratum sums.  So that route, too, does not
produce new level-only content.

THE BARRIER, NOW ESTABLISHED RATHER THAN CONJECTURED.  With the failure
hypothesis REMOVED entirely, the full hand net (levels, L1'', L7, L7', L11,
L12, L14-L16 and the A3 anchors) is CONSISTENT on every one of the 105
impossible survivors -- 0 of 105 are hand-excluded outright
(impossible_split.json).  So the 105 are not reachable by any level-only
argument built from the current lemmas; they require statements that reference
actual coalition values.

TARGET (a), THE FIVE T1 CONFIGURATIONS: A SHARP NEGATIVE.  Tracking every
assertion and asking for a minimal unsat core (core5.py) over the hypothesis
set the assignment proposed -- levels, both core memberships, v >= 0, the A3
anchors, the A3 global inequalities, and the protectors in their tight form --
returns SAT for all five.  So that toolkit is PROVABLY INSUFFICIENT for them;
they need the full staged Farkas ladders, and no case analysis against
L7/L7'/L11/L12 + anchors can work.  This does not close (a), but it stops the
proposed line of attack from being retried and says exactly what is missing.
