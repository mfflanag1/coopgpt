1. Original TexMex ANN datasets and format documentation
   http://corpus-texmex.irisa.fr/
   Original archive: ftp://ftp.irisa.fr/local/texmex/corpus/siftsmall.tar.gz
   Original checksum list: ftp://ftp.irisa.fr/local/texmex/corpus/MD5SUM
   Read/acquired: 14 October 2026 UTC.
   Primary-page bytes SHA256:
   0fa52297e5f5b92820296f7b617368e4d31e75ebe667a199879f9e77fce7a7e3

   The publisher names ANN_SIFT10K as 10,000 base, 100 query and 25,000 learning
   vectors, each 128D. fvecs/ivecs have a little-endian Int32 dimension prefix on
   every row. Groundtruth is 100 zero-based nearest-neighbor IDs per query, ordered
   by squared Euclidean distance. A tie-break is not specified. The dataset page
   carries a CC0 waiver by Laurent Amsaleg and Hervé Jégou, published from France:
   https://creativecommons.org/publicdomain/zero/1.0/
   Retain that attribution with this included copy of the unmodified data.

   DATA_MANIFEST.json records exact archived/extracted hashes, counts, observed
   coordinate/norm bounds and exclusions. MD5SUM.source.txt is the actual small
   publisher checksum file. SOURCE_FETCH.json records retrieval attempts, including
   the rejected HTTPS hostname mismatch; TLS checks were never disabled. The
   original published FTP endpoint supplied the archive. No unofficial mirror,
   data normalization, learned representation or proprietary corpus is involved.
   Full original HTML is retained only as a local acquisition cache; the above
   source URL/hash and this summary are published. Learning vectors remain unused.

   Associated established literature identified by the original dataset page:
   Hervé Jégou, Matthijs Douze, Cordelia Schmid, Product quantization for nearest
   neighbor search, IEEE TPAMI 33(1), 2011; https://hal.inria.fr/inria-00514462
   The page explicitly associates that paper with SIFT1M/GIST1M. We do not infer
   that SIFT10K first appeared in it, or claim product quantization as our method.

2. Faiss developers' primary documentation (method context, no Faiss installation)
   https://github.com/facebookresearch/faiss/wiki/Faiss-indexes
   https://github.com/facebookresearch/faiss/wiki/MetricType-and-distances
   Read: 14 October 2026 UTC. Exhaustive squared-L2 search and flat vector storage
   are established methods. Squared L2 preserves Euclidean neighbor ordering;
   cosine/normalization defines a different contract. This experiment implements
   conventional exhaustive search and does not claim to outperform Faiss.

3. Apple primary API documentation and installed SDK headers
   https://developer.apple.com/documentation/metalperformanceshaders/mpsmatrixmultiplication
   https://developer.apple.com/documentation/metal/mtlresourceoptions/storagemodeshared
   MPSCoreTypes.h defines optional reduced precision; it is explicitly disabled.
   Installed SDK: /Library/Developer/CommandLineTools/SDKs/MacOSX.sdk
   BUILD_NOTES.txt specifies actual compilation and API/memory choices.

What this project adds here
A Mac-native implementation, strict exactness/tying contract, fixed qualification
cohort, independently recomputed certificates and explicit evidence boundaries.
These are reproducibility/engineering artifacts, not a new mathematical theorem,
search algorithm, economic result or field-level breakthrough. SIFT features
are classical image descriptors; this is not language-model answer evaluation.
