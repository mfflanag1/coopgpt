Absolute literals versus runtime provenance
There are zero absolute path/URL string literals in the runner and six
selected Python sources, and zero such strings in the three complete fixture
contents. Manual reading also found no local import, sys.path alteration,
eval/exec/runpy, custom dynamic import, network client, or source acquisition.
The AST inventory is supporting evidence; the conclusion is based on reading
the complete source, not assuming a regex is a general dependency proof.

Paths generated at runtime have clear roles: sys.executable identifies the
current installed Python; --out or tempfile selects a fresh output directory;
the report's source_root/output_root and its recorded command are provenance.
They do not cause the checkers to reopen an old campaign. A host-specific
path in a saved replay report is not an executable fallback dependency: no
selected checker reads such a report. Current working directory does not
select the campaign source root; __file__ does.
