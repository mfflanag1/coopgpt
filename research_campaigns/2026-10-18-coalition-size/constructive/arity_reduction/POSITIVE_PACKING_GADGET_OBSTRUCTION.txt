ARITY REDUCTION BY OWNER-LOCAL POSITIVE PACKING: A QUANTIFIED OBSTRUCTION
2026-10-18. Structural consequence for a specified reduction architecture.
The rank charging inequality below is an established campaign ingredient;
its gadget-obstruction consequence is the point of this note. No novelty claim.

1. REUSED BOUNDED-ARITY DELETION-LOSS INEQUALITY
Let G(c)=max{pi.x:Ax<=c,x>=0}, A,pi>=0, with every positive-profit column using
at most q rows and no positive-profit resource-free column. Suppose its value
at c is finite. Let u_1,...,u_r be arbitrary nonnegative resource bundles with
sum_j u_j<=c. The unallocated remainder may contain any fixed auxiliary stock.
Then
  sum_(j=1)^r [G(c)-G(c-u_j)] <= q G(c).                 (1)
The u_j may aggregate fixed blocks of actual owners; resources can be supplied
by many blocks, and no strategic owner is split inside a report comparison.

Proof. Fix an optimal production plan x. Discard zero-profit activities. For
a used row v, c_v>0; write theta_jv=u_jv/c_v. Thus sum_j theta_jv<=1. For each
positive used activity e, put t_je=max_(v:A_ve>0) theta_jv. The plan
  x^-j_e=x_e(1-t_je)
is feasible at c-u_j: its use of row v is at most
  (1-theta_jv) sum_e A_ve x_e <= c_v-u_jv.
Therefore G(c)-G(c-u_j)<=sum_e pi_e x_e t_je. Sum over j and use
  sum_j max_(v in supp(e))theta_jv
     <=sum_(v in supp(e))sum_j theta_jv<=|supp(e)|<=q.
This proves (1). Unused zero-capacity rows do not appear in positive used
activities; define their fractions0 if desired. The fixed remainder only
reduces the sum of fractions and cannot invalidate the argument.

In particular some j satisfies
                    G(c-u_j)>=(1-q/r)G(c)               (2)
when r>q. A qualitative consequence, when c is pooled actual-owner stock, is
that any positive production has a positive witness using at most q actual
owners: choose one positive supplier for each row of one positive-profit
activity and run a sufficiently small amount using their bundles. If some
fixed auxiliary stock is instead supplied outside the owner bundles, the witness
uses at most q owner bundles TOGETHER WITH that fixed stock whenever coalition
production includes it. No removal of public auxiliary stock is implicit.

2. NO OWNER-LOCAL MULTIPLICATIVE EMBEDDING OF HIGHER-ORDER UNANIMITY
Consider r original owners, owner j reporting x_j in[0,1], and original value
  F(x)=min(x_1,...,x_r).
Allow an arbitrary finite arity-q packing technology G, arbitrary extra rows,
and arbitrary owner-local nonnegative report maps Phi_j(x_j). Phi_j may be
nonlinear and may output resources for an arbitrarily large fixed block of
new agents assigned to original owner j. Also allow an arbitrary fixed
nonnegative auxiliary baseline a. Write
                   c(x)=a+sum_j Phi_j(x_j).             (3)
This is broader than keeping exactly the original actual-owner roster. No
monotonicity or zero-at-zero condition on Phi_j is needed for the obstruction.
A valid binding-underreport transfer would normally also require monotonicity.

At x=1, set c=c(1), u_j=Phi_j(1). Zeroing original owner j gives
  c(1 with x_j=0)=c-u_j+Phi_j(0)>=c-u_j.
By monotonicity of packing value and (1),
  sum_j G(c(1 with x_j=0)) >= (r-q)G(c(1)).              (4)
Thus one original zero-worth profile retains at least a 1-q/r fraction of the
full gadget value. This holds even if the local maps themselves are not
monotone, and even with fixed auxiliary stock or owner-block replication.

For r>q there are NO constants alpha,beta>0, finite, such that
       alpha F(x)<=G(c(x))<=beta F(x) for every x in[0,1]^r.  (5)
Indeed the full profile has G>=alpha, while every one-owner-zero profile has
original value0 and so would require G=0, contradicting (4).
In particular q=3 cannot multiplicatively represent a min_r seed for r>3.
The obstruction already uses r+1 binary profiles, all on one fixed report box.
It therefore applies a fortiori to an all-real report transfer. Each higher-
arity binary-circuit institution contains such a supported single-circuit seed
with all other original reports0, so a uniform value-preserving reduction of
those technologies encounters the same obstruction.

Report locality matters. The nonlocal map assigning min_j x_j to one new
resource trivially represents the grand value with arity1, but a restoration
by any other original owner changes somebody else's mapped report. It therefore
does not preserve the original protected coalition, and it does not preserve
coalition values. That construction is outside (3) and is not an incentive
transfer merely because the grand objective is numerically correct.

3. ALL-COALITION AND ADDITIVE VERSIONS
At a single profile of the original r-owner unanimity game, every proper
coalition has value0. No arity-q image with the same actual owners can satisfy
positive finite two-sided multiplicative bounds on ALL coalition values when
r>q: positive grand value would have a positive coalition witness of size<=q.
This fixed-profile statement does not even require a report-map locality
assumption. A map promising only selected coalition inequalities is outside it.

If the full gadget value is at least alpha and each one-owner-zero image has
value at most epsilon, then (4) forces
                       epsilon >= (1-q/r) alpha.        (6)
For a constant additive offset model G(c(x))=B+alpha F(x) on these r+1 profiles,
(4) gives the sharper offset requirement
                       B >= (r/q-1) alpha.              (7)
With uniform additive error epsilon around B+alpha F, the necessary condition is
                  q B+(2r-q)epsilon >= (r-q)alpha.       (8)
These are necessary conditions, not impossibility results for every approximate
or offset-based certificate construction. Ordinary multiplicative funding at
original zero-production profiles cannot absorb a positive offset by rescaling.

The fractional bound (2) is sharp. For r>=q, create one disjoint unit-profit
q-input activity for every q-subset T of the r owner groups. Give each activity
its own q distinct rows, one owned by each member of T, with full capacities
1/binom(r,q). Every activity can run independently. Grand value is1; deleting
any one group leaves exactly binom(r-1,q)/binom(r,q)=1-q/r. Owners may own many
separate rows. This is a sharpness example for the reused deletion inequality,
not a value-preserving gadget for min_r or a new funding lower bound.

4. WHY BASIC AUXILIARY-VARIABLE GADGETS DO NOT EVADE THE OBSTRUCTION
Zero-profit activities in positive packing do not transmit intermediate output.
If a proposed extended LP has productive variables x and auxiliary variables z,
  max pi.x subject to A x+B z<=c, x,z>=0, A,B>=0,
then setting z=0 only relaxes the constraints. Its projection on x is exactly
{x>=0:A x<=c}; the zero-profit variables can be deleted. To force a later stage
t to wait for an earlier stage z one ordinarily writes t<=z, which has a
negative coefficient in t-z<=0. Positive packing alone supplies no such link.
Splitting profit among stages instead allows local production; Sections1--2
then apply to those positive-profit activities.

The dual-cover version is equally transparent. A new auxiliary resource with
zero supplied capacity has a zero-cost nonnegative dual price. If every cover
constraint contains at least one such auxiliary price with a positive
coefficient, those prices alone can satisfy all finitely many constraints at
zero objective cost. The alleged production value is then0. Any remaining
constraint using only original positive-capacity rows corresponds to a local
positive activity, which again has a witness of size at most q.
Fixed positive auxiliary capacities can avoid zero value, but reintroduce the
baseline/false-production restriction (4); they do not yield (5).

SCOPE AND CONSEQUENCE FOR THIS CAMPAIGN
This rules out exact or bounded multiplicative owner-local positive-packing
value reductions from general arity to arity3. It does NOT rule out a bespoke
certificate transfer that preserves only selected comparisons, changes the
payment argument, allows nonlocal report encodings with a separately proved
incentive theorem, or exploits a controlled report-dependent additive baseline.
No improvement to the arity3 general lower or upper frontier follows here.
