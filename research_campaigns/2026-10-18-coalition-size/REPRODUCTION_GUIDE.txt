SIMPLE PORTABLE REPLAY
Extract the handoff archive. Open a terminal in this campaign directory:
  research-campaigns/2026-10-18-coalition-size
With Python3 available, run:
  python3 reproduce_campaign.py --suite basic

The basic suite uses only the Python standard library. Python assertions
must stay enabled: do not use -O/-OO or set PYTHONOPTIMIZE. The runner refuses
optimized mode before executing evidence. It checks projective geometry
through M4, scalar certificates through M64, the exact symbolic
identities in the checker, and the bounded-coalition tail/peak certificates
at the checker's declared finite ranges. Output goes into a new temporary
directory and its path is printed. Use --out /a/new/directory to retain it
at a chosen location. The output directory must not already exist.

EXTENDED PORTABLE REPLAY
If an existing Python environment has NumPy and SciPy, run:
  python3 reproduce_campaign.py --suite extended

This additionally runs the exact general-arity supporting checks, the saved
original-variable projective lift, independent CEA region/endpoint checks,
and seven independent fixed-partition synthesis fixtures. SciPy proposes
LP solutions in the synthesis checker; rational primal/dual certificates
are checked exactly before PASS. Nothing is installed automatically.

The runner copies every selected checker and fixture to its fresh output
directory, records their SHA256 hashes, and runs there. It never overwrites
sealed scientific outputs. Every subcheck must both exit successfully and
emit an explicit PASS result. REPLAY_REPORT.json records the execution,
source hashes, scope and output hashes. These checks can take several minutes.

WHAT THE CHECKS DO NOT ESTABLISH
Finite computation does not prove the unbounded symmetrization theorem,
the whole real-domain argument, historical novelty, or external peer review.
The all-size arguments are conventional written proofs. The basic and extended
suites are selected evidence; they do not replay every exploratory LP, every
earlier CoopGPT campaign, all public data access, or every cited source.

The exact lift's 34,440 rows cancel 26,040 actual payment coordinates over
5,880 profiles and yield K>=4/3. It is a finite original-variable witness,
not a separate theorem beyond the main construction. CEA's14 rational regions
and90,396 endpoint comparisons concern three actual mixed owners/two pools;
its all-size/full-real claim uses the accompanying bottleneck proof. The
fixed-partition optima concern precisely the supplied partitions.
