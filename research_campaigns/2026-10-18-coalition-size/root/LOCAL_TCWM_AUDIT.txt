LOCAL DIFFERENTIAL TEST FOR TCWM (ELEMENTARY AUDIT TOOL)

Fix an actual owner's report coordinate b_{jv}. At a differentiable profile set
a_i = partial y_i / partial b_{jv}. Coalition TCWM for infinitesimal restorations
in that coordinate requires sum_{i in C} a_i>=0 for every protected C containing
j with |C|<=s, including all members whose reports are unchanged.

Equivalently, a_j plus the sum of the min(s-1,n-1) most negative entries among
(a_i:i!=j), omitting nonnegative entries, must be nonnegative. The minimizing
coalition simply selects those entries. This converts a local exponential
coalition check into sorting.

For a box report domain, suppose payments are continuous and absolutely
continuous along every coordinate segment. If the sorted-sum inequality holds
at almost every point OF EACH SUCH SEGMENT (one-dimensional measure), it implies
TCWM: restore each coalition member's coordinates one at a time and integrate. The
same protected coalition is used throughout, including unchanged members.
Piecewise differentiable formulas must also have their interfaces checked.
Without absolute continuity, a derivative calculation does not rule out jumps.
An almost-everywhere statement only in the ambient multidimensional measure
does not suffice: an entire coordinate segment can be an exceptional null set.
The cone application has a different feasible-deviation domain; coordinate
restoration paths need not remain feasible there, so this box argument must
not be transferred to that application without a valid path argument.

This test proves only payment monotonicity. It does not prove full OUT. When
complementary resources are restored together, F(sum_C d_i) can be positive
despite being zero on every individual coordinate increment. A separate finite
increment argument is required for the full-OUT RHS.

This is a routine characterization used for screening, not a claimed novel
structural lemma or a campaign success by itself.
