BASIC REPLAY ONLY
After extracting specialist_packet.zip, open a terminal in specialist_packet:

  python3 reproduce_campaign.py --suite basic

Python3 and its standard library are sufficient. Assertions must remain enabled:
do not use -O/-OO or set PYTHONOPTIMIZE. The exact copied runner refuses optimized
mode and removes PYTHONOPTIMIZE from child environments. Its default output is
a fresh temporary directory. To choose a retained location, append
--out /a/new/directory; that directory must not already exist.

The runner copies the selected checkers to fresh output directories, verifies
copy hashes, and requires successful exit plus explicit PASS output. The basic
suite checks geometry through M4 and scalar certificates through M64, plus the
bounded-coalition tail checker's declared finite ranges. The historical filename
projective_cube_root_check.py is preserved exactly; its contents also check the
stronger square-root statements. Finite replay does not prove the all-size or
all-real theorem; those claims rest on the included written arguments.

Extended-suite inputs are deliberately NOT included. Do not run --suite extended
from this packet. The unmodified runner still exposes that option; a complete
