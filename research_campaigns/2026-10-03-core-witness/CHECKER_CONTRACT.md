# Independent checker contract v1

Implement src/check_certificate.py, standard library only, with check(data)->dict and CLI path. Do not import the solver/generator. Reconstruct everything from m and P and semantic certificate fields. Require explicit ValueError or other fail-closed exceptions (never assert for scientific checks), works under python -O. Certificate JSON:
- schema='core-witness-v1'; m positive integer (bool forbidden); P list of length3 integer label triples, all labels0..m-1, sectorwise disjoint; empty/perfect P allowed.
- unmatched: sorted actual global player IDs s*m+j outside P, must match reconstruction.
- support: sorted list of [pair_type,a,b], types0 AB,1 AC,2 BC, exactly diagonal+P pair union.
- matrices: 3 lists of m rows of m rational values, zero outside support; all nonnegative. Rational data are integers (not bool) or strings in the grammar signed integer, signed integer/positive integer, or signed plain decimal (no whitespace, exponent or leading-dot syntax); reject float.
- witness_targets: actual unmatched array if nonempty, else [-1] as a dummy core witness. Must match reconstruction.
- witnesses: same number as targets, each 3m rational coordinates, nonnegative, total1, covers ALL m^3 triples from raw matrices. Sum diagonal team values1. All supported weights and payoff coordinates <=1.
- primal_J: rational, must equal sum P team worth + sum target coordinate/3 -1, no dummy target term.
- dual object: lambda list entries [target,a,b,c,mass], unique (target,a,b,c), nonnegative rational mass, target in witness_targets and valid team. normalization rational nu0; totals list rational nus ordered witness_targets; upper rational claimed bound.

Compute exact residual for objective 3*w(P)+sum x_i^i (coefficient 3 on each pair occurrence of P,1 on each true target coordinate). Subtract lambda*(team pair coefficients - witness payoff coefficients) and nu0*diagonal coefficients and each nu*sum payoff coefficients. All variables in [0,1], so upper=(nu0+sum nus+sum positive residuals)/3-1. Validate upper equals claimed, primal_J<=upper. Do NOT require upper<1/3 (we need counterexample search too), do NOT require primal=upper. Return exact lower/upper/gap and equality flag and dimensions. No scientific use of metadata status or floating results.

Malformed input rejection matters: core violation, bad diagonal total, objective mismatch, witness total, P overlap, off-support nonzero, unmatched-set wrong, empty dual claiming falseupper. Tests independent from production coefficient logic: tiny m1 perfect diagonal pairAB1, witness(1,0,0), P(0,0,0), J0, dual normalization3, totals[0], no lambda, upper0. Tiny m1 emptyP sameweights, witnessesfor0=(1,0,0),for1=(0,1,0),for2=(0,0,1), all valid because teamworth1, J0, dual normalization0, totals[1,1,1], no lambda, upper0. For offsupport use m2 emptyP diagonal AB entries1/2; A/B witnesses pay their own target1/2 and the other diagonal A player1/2; C-target witnesses pay both A players1/2 and their own C coordinate0. All cover, diagonal total1, objective -1/3; totals all1 gives upper1 (valid gap), since residualnegativeorzero. Deliberate wrong exact upper0 without needed proof should fail. Tests may add own clear examples. Tests must NOT run new LP search.
