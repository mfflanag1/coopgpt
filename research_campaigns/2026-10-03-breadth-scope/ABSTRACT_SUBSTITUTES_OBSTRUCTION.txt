Why source substitutes alone do not prove joint core-ideal attainment

A. Fable five-player obstruction, checked by Codex QA and coordinator.
N={1,2,3,4,5}, S={1,2}. Give basic coalitions 34 value1 and145,235 value2.
Every proper coalition's value is the maximum basic value it contains (0 if
none), and v(N)=3. Positive basic coalitions pairwise intersect, so disjoint
coalitions cannot both have positive value; monotonicity proves superadditivity.
Core points x=(1,0,1,0,1), y=(0,1,0,1,1) cover all three bases and have total3.
Deletion bounds give H1,H2<=1, and x,y attain1 separately. Summing the three
basic core constraints gives 2T-x1-x2>=5, hence x1+x2<=1, forbidding joint ideals.
For each fixed R subset{3,4,5}, Q->v(R union Q) on S is modular: for R=empty or
singletons all values vanish; R=34 gives constant1; R=35 gives2 iff2 is present;
R=45 gives2 iff1 is present; R=345 gives1+indicator1+indicator2. This verifies
every slice directly, without a computational instance. The game is even totally
balanced: every proper subgame's positive bases have a common player (it cannot
contain both145 and235), to whom its grand value can be allocated. N has x,y.
Limitation: v(N minus S)=1>0, so S is not the full source-arc set of a flow game.

B. Coordinator strengthening: a necessary source set does not repair the lemma.
Parameter lambda>0. N={1,2,a,b,c,d}, S={1,2}, R={a,b,c,d}. Four basic coalitions:
 A={1,b,c,d}, B={1,a,c,d}, C={2,a,b,d}, D={2,a,b,c}.
Each has value2lambda. Set v(N)=3lambda; every proper coalition containing a
basic coalition has value2lambda, all other proper coalitions have value0.

Monotone and superadditive: every pair of bases intersects. Thus two disjoint
coalitions cannot both be positive, and monotonicity gives superadditivity.
All coalitions disjoint from S have value0, so S is necessary for positive worth.
For fixed R' subset R, v(R')=0. Each singleton-source value is0 or2lambda.
If R' is proper, v(R' union S) is their maximum. If R'=R, these two values are
2lambda each and v(R union S)=3lambda. Consequently
 v(R' union{1})+v(R' union{2}) >= v(R' union S)+v(R')
for EVERY R', which is precisely submodularity on a two-player set.

Core witnesses in order(1,2,a,b,c,d):
 x=lambda(1,0,1,1,0,0), y=lambda(0,1,0,0,1,1).
Each covers all four bases at equality and sums to3lambda, so covers every
coalition. T-v(N minus i)=lambda for i=1,2; the witnesses attain these bounds,
so H1=H2=lambda. Every a,b,c,d appears in three bases and1,2 each in two:
 x(A)+x(B)+x(C)+x(D)=3T-x1-x2 >=8lambda.
Thus every core point satisfies x1+x2<=lambda, so their two ideals cannot be
jointly attained. The loss is not fixed by marginal equality, total balancedness,
or the fact that every positive coalition needs a member of S.
For total balancedness: a proper coalition cannot contain a base from{A,B} and
one from{C,D}, because their union isN. The bases on either one side have a
common downstream player. Allocating the subgame's grand value there is core;
zero subgames have the zero allocation. The full game has x,y.

C. The property actually possessed by source arcs.
In an arc-player flow game, fix arbitrary non-source arcs R' and let Q vary over
a set of source arcs. For Q1,Q2 choose minimizing cut source sides U1,U2. Cut
submodularity for fixed arcs, and the elementary source-arc indicator inequality,
give
 cut_(Q1)(U1)+cut_(Q2)(U2)
 >=cut_(Q1 union Q2)(U1 union U2)+cut_(Q1 intersect Q2)(U1 intersect U2)
 >=v(R' union Q1 union Q2)+v(R' union(Q1 intersect Q2)).
For a source arc in both Q's, its two indicators equal the union/intersection
sum; for one present in just Q1, being outside U1 dominates being outside
U1 union U2, and similarly for Q2. This proves conditional submodularity.
If S contains ALL source arcs, v(N minus S)=0. PartB shows that these two
properties do not by themselves prove joint attainment, even in totally
balanced games. More network structure is needed.

D. Scope and next mathematical obstruction.
No representation of either example as a one-arc-per-player short-path flow game
has been established. In B the minimal positive coalitions have four players,
whereas a minimal positive coalition in a flow game contains a positive s-t
path and therefore, in our test class, has at most three. This identifies an
actual mismatch, not a C2 counterexample. The obstruction is a weighted sum of
OVERLAPPING coalition constraints. Single complement-of-source-set bounds miss it.
A worthwhile next argument must use path structure to control such weighted
families, or produce a flow-realizable obstruction. Merely invoking source
submodularity or reduced-game balancedness cannot complete the proof.
The all-instance subsidy theorem in the unit-capacity case remains intact.
