1. GRAPH CONVENTION AND EXPLICIT SETS.
Let the graph have vertex set Z/(2L)Z, cyclic edges and antipodal edges of
cyclic difference L. Write top j=j and bottom j=L+j for0<=j<L. An occupied
rung chooses one of these two vertices. Encode top by sign+1 and bottom by-1.
The focal closed neighborhood is C={0,1,L,2L-1}.

For each even h in{2,4,...,L-2}, define four independent-set candidates.
The listed holes contain neither vertex; every other rung j contains the
vertex of sign s_j=tau_j*(-1)^j.

  Family  holes             tau_j on occupied rungs
  A       {h-1,h,h+1}       +1 for j<h, -1 for j>h
  B       {1,h,L-1}         -1 for j<h, +1 for j>h
  C       {0,h,h+1}         -1 everywhere
  D       {0,h-1,h}         +1 everywhere

Put m=(L-2)/2. There are4m=2(L-2) candidates, each given probability1/(4m).
Each listed triple consists of three distinct rungs for L>=4. Thus each set
has exactly L-3 vertices and never contains both ends of an antipodal edge.

2. INDEPENDENCE, INCLUDING THE TWISTED SEAM.
For adjacent rungs j,j+1 with0<=j<L-1, cycle edges join equal labels: top to
top and bottom to bottom. If both are occupied, independence therefore
requires s_(j+1)=-s_j, equivalently tau_(j+1)=tau_j. This holds in C and D
because tau is constant. It holds in A and B because every change of tau is
separated by a hole at h (and A has the additional holes h-1,h+1).

The remaining two cycle edges join top(L-1) to bottom0 and bottom(L-1) to
top0. If both endpoint rungs are occupied, independence requires the SAME
selected sign on rungs0 and L-1. Since L is even, this is equivalent to
tau_(L-1)=-tau_0. Family A satisfies it whenever both rungs are occupied:
tau_0=+1 and tau_(L-1)=-1. In B, rung L-1 is a hole; in C and D, rung0 is a
hole. The seam therefore never creates an edge. This verifies all graph edges
for every candidate, with no finite-size or drawing convention assumption.

3. CLOSED-NEIGHBORHOOD MARGINALS.
Every A set contains exactly focal top0 from C. Its rung1, when occupied,
chooses bottom1; its last rung, when occupied, chooses top(L-1).
Every B set contains exactly bottom0=L from C, since rungs1 and L-1 are holes.
Every C set contains exactly top1 from C; rung0 is a hole and the last rung,
when occupied, chooses top(L-1).
Every D set contains exactly bottom(L-1)=2L-1 from C; rung0 is a hole and
rung1, when occupied, chooses bottom1.
Each family has m sets. Hence every local vertex occurs m of4m times, with
marginal1/4, and every supported set intersects C in exactly one vertex.
