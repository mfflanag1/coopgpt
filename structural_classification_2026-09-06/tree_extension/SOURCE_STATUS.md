# Source and priority status for the all-tree extension

September 6, 2026. Bounded audit only; novelty unconfirmed. The earlier source records remain in the parent structural-classification checkpoint and the chain-cycle paper package.

The new theorem concerns STRICT full-sector teams. It does not claim the first tree balancedness theorem, a new assignment model, or a new general lattice/LP algorithm. The proof uses classical optimal bipartite matching, a direct strict-core cut representation, and elementary minimum closure of difference constraints. The proposed contribution is the sharp full-leximin/whole-core-ideal guarantee on every fixed tree, including branching, with the stated strict model and quantifiers.

Atay and Nunez (2019), Multi-sided assignment games on m-partite graphs, DOI10.1007/s10479-019-03256-5, proves tree decomposition in a model allowing smaller productive coalitions. Its original publisher text and precise difference from strict Stuart/Quint models were read in the preceding audit. URL: https://link.springer.com/article/10.1007/s10479-019-03256-5 . The present strict-core clipping proof is self-contained; no inference from a smaller core is used.

The classical lattice property for bilateral assignment cores is prior work and must be credited. The current proof does not assert that the entire strict tree payoff core is closed under ordinary coordinatewise minima; that would generally conflict with efficiency. Minimum closure is used only for the per-cut difference inequalities, followed by a separate nonnegative, efficient reconstruction argument.
