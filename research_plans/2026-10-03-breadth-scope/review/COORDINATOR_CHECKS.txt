Coordinator design checks, 3 October 2026. These are preparation/calibration
arguments, not execution of the proposed campaign or claims of novelty.

Single-path control: with m unit-capacity arcs, only the whole player set has
positive worth (one). The core is the unit simplex, each H_i=1, and the protected
minimum total payment is max(1,m alpha). Hence s_alpha=max(0,m alpha-1).

Generic baseline for 0<=alpha<=1: fix any original core allocation x. Let
y_i=max(x_i,alpha H_i). It covers every original coalition because y>=x.
Since 0<=x_i<=H_i, max(0,alpha H_i-x_i)<=alpha(H_i-x_i). Consequently
s_alpha<=alpha(sum_i H_i-T). This is a generic construction, not a proposed
new result; numerical/computational rediscovery cannot pass the impact gate.

Bounded-path flow control: choose one maximum flow f in the DAG and decompose it
into directed source-sink paths. Removing all its path flow using arc e discards
f_e units, so v(N\{e})>=T-f_e. Core coverage on N\{e} gives H_e<=T-v(N\{e})<=f_e.
Every decomposition path has length at most three, so sum_e H_e<=sum_e f_e<=3T.
Combining with the generic baseline gives s_(1/3)<=2T/3. Thus a proposed T/3 bound
in this flow class would require more than this immediate argument. The argument
concerns all core points, not merely the Owen set, and does not assert that H_e
equals f_e or equals the deletion marginal. It also handles unused and zero arcs.

Four-sector planning arithmetic: weighted average of the displayed hypothetical
bounds V<=8T-2 beta-E/3 and V<=4T+beta-C2/k with weights 1/3,2/3 is
V<=16T/3-E/9-2C2/(3k). Cancellation therefore does not fail merely because the
beta coefficients differ. The two premises and k=0 must still be independently
derived before treating the K=4 upper bound as established campaign progress.
